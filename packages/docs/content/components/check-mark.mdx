# Check mark

목록에서 선택된 항목을 표시하는 체크 표시예요.

<ComponentBadges />

<Figure height={240} />

선택 표시만 필요할 때 쓰고, 값을 고르는 폼 컨트롤은 Checkbox를 써요.

|         | Check mark                                      | Checkbox                      |
| ------- | ----------------------------------------------- | ----------------------------- |
| 모양    | 체크 아이콘만 보여요                            | 체크 박스예요                 |
| 쓰는 곳 | 선택된 항목을 표시하는 목록 (Menu, Select Item) | 여러 개를 고르는 폼           |
| 선택    | 항목 전체를 눌러 선택해요                       | 박스나 레이블을 눌러 선택해요 |

## Examples

  items={[

    },
    { title: "촘촘한 목록", name: "check-mark/Tight" },
    { title: "상태", name: "check-mark/States" },
    { title: "반응형", name: "check-mark/Responsive" },
  ]}

- **하나만 고르기**: 정렬처럼 하나만 고르는 목록이에요. `role="radio"`를 주고, 항목 폭으로 넓혀(`className="w-full"`) 항목 전체를 누르게 해요.
- **여러 개 고르기**: 필터처럼 여러 개를 고르는 목록이에요. 기본 역할(`checkbox`)로 읽혀요.
- **크기**: `size`는 `xs`(16) · `sm`(20, 기본) · `md`(24) · `lg`(32)예요. 레이블 글자와 높이도 함께 바뀌어요.
- **촘촘한 목록**: `tight`는 바깥 여백을 없애요(높이는 내용만큼, `sm`은 24). 선택 목록(listbox) 안에서는 `role="option"`을 줘요.
- **상태**: 체크 안 됨은 회색, 체크됨은 브랜드 색이에요. `disabled`는 연한 회색 체크와 회색 글자예요.
- **반응형**: `size`는 구간별 값도 받아요. `{ base: "md", desktop: "sm" }`면 모바일·태블릿은 체크 24, 데스크톱(1024px)부터 20이에요. 창 폭을 바꿔 보세요.

## Props

나머지 `<button>` 속성도 그대로 받아요.\
서버 컴포넌트에서 바로 쓸 수 있고, `onClick`을 넘길 때만 클라이언트 컴포넌트 안에서 써요.

| 이름         | 타입                                                                         | 기본값       | 설명                                                                            |
| ------------ | ---------------------------------------------------------------------------- | ------------ | ------------------------------------------------------------------------------- |
| `checked`    | `boolean`                                                                    | `false`      | 선택 여부. 선택되면 브랜드 색으로 바뀌어요                                      |
| `size`       | `"xs" \| "sm" \| "md" \| "lg"` 또는 `{ base, tablet, desktop }`              | `"sm"`       | 체크 16 · 20 · 24 · 32. 레이블과 높이도 따라가요. 객체로 주면 구간마다 달라져요 |
| `children`   | `ReactNode`                                                                  | -            | 레이블. 없으면 `aria-label`을 줘요                                              |
| `disabled`   | `boolean`                                                                    | `false`      | 누를 수 없는 상태                                                               |
| `tight`      | `boolean`                                                                    | `false`      | 바깥 여백을 없앤 촘촘한 모양(높이 40 → 내용 높이)                               |
| `role`       | `"checkbox" \| "radio" \| "option" \| "menuitemcheckbox" \| "menuitemradio"` | `"checkbox"` | 눌릴 때 스크린리더가 읽는 역할. `option`은 `aria-selected`로 알려요             |
| `aria-label` | `string`                                                                     | -            | 레이블 없이 쓸 때의 이름                                                        |
| `onClick`    | `(event) => void`                                                            | -            | 주면 항목 전체가 눌리는 버튼이 돼요. 없으면 표시용이에요                        |

## Guidelines

<CheckMarkGuide />

- 선택된 항목에만 체크를 보여서 위치를 분명히 해요.
- 항목 전체를 눌러서 선택되게 해요. 체크가 작아도 버튼 전체가 눌림 영역이에요.
- 터치 영역은 44px 이상이에요. 보이는 높이가 40·24여도 터치 화면에서는 눌림 영역이 44px로 넓어져요.
- 폼에서 값을 입력받는 용도로 쓰지 않아요. Checkbox를 써요.
- 체크 색만으로 선택 여부를 알리지 않아요. 스크린리더에는 `aria-checked`·`aria-selected`로 알려요.
- `tight`는 촘촘한 목록에서만 써요.
- 레이블 없이 쓰면 `aria-label`을 붙여요.
