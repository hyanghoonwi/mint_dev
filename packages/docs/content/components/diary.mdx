# Diary

날짜별 일정을 가로로 넘겨 볼 때 쓰는 날짜 칸 줄이에요. 요일, 날짜, 일정 칩이 한 칸에 쌓이고 누르면 그날을 골라요. 오늘 3일 전부터 오늘 2개월 뒤까지 보여 줘요.

- **기본**: `today`를 기준으로 3일 전부터 2개월 뒤까지 칸을 이어서 보여 줘요. `value`·`onChange`로 고른 날을 다뤄요. 오늘은 요일 글자가 "오늘"로 바뀌고 파란 윗줄이 생겨요.
- **일정 더보기**: 칩은 `maxEvents`(기본 2)개까지만 보이고, 넘치는 개수는 `+N`으로 알려요.
- **이미지 칩**: 일정에 `image`를 주면 문구 앞에 16px 동그란 이미지가 붙어요. 문구가 길면 칩 안에서 말줄임으로 보여요.
- **공휴일**: 일요일은 자동으로 빨간 글자예요. 공휴일은 `holidays`로 날짜와 이름을 넘겨요.
- **지난 날**: `min`보다 앞선 날은 50% 흐려지고 누를 수 없어요. `disabledDates`로 특정 날만 막을 수도 있어요.
- **가로 스크롤**: `Diary`는 부모 폭을 따라가요. 부모가 칸(96px)을 모두 보여 줄 수 없을 만큼 좁으면 가로로 넘겨요. 폭을 정하는 부모는 `Box`에 `className`으로 폭을 줘서 만들어요. 넘친 쪽 가장자리가 흐려지고, 마우스는 끌어서 넘겨요.

## Props

나머지 `<div>` 속성도 그대로 받아요.\
클라이언트 컴포넌트라서 `onChange`는 클라이언트 컴포넌트 안에서 넘겨요.

| 이름            | 타입                                  | 기본값 | 설명                                                             |
| --------------- | ------------------------------------- | ------ | ---------------------------------------------------------------- |
| `value`         | `string \| null`                      | -      | 선택한 날(제어)                                                  |
| `defaultValue`  | `string`                              | -      | 처음 선택한 날(비제어)                                           |
| `today`         | `string`                              | -      | 오늘(`YYYY-MM-DD`, 필수). 이 날 기준으로 보여 줄 기간이 정해져요 |
| `holidays`      | `Record<string, string>`              | -      | 공휴일(날짜 → 이름). 빨간 글자로 보여요                          |
| `disabledDates` | `string[]`                            | -      | 누를 수 없는 날                                                  |
| `min`           | `string`                              | -      | 이 날보다 앞선 날은 흐려지고 누를 수 없어요                      |
| `events`        | `Record<string, { label, image? }[]>` | -      | 날짜별 일정. `image`는 문구 앞 16px 동그란 이미지예요            |
| `maxEvents`     | `number`                              | `2`    | 한 칸에 보이는 칩 수. 넘치면 `+N`으로 알려요                     |
| `onChange`      | `(date: string) => void`              | -      | 칸을 누르면 불려요                                               |

## Guidelines

<DiaryGuide />

- 보여 주는 기간은 오늘 3일 전부터 오늘 2개월 뒤까지로 정해져 있어요. 시작일이나 칸 수는 바꿀 수 없어요. 2개월 뒤 날짜에 같은 날이 없으면 그 달의 마지막 날까지예요.
- 일정 칩은 최대 2개까지만 보여 주고 나머지는 `+N`으로 알려요.
- 일정 종류는 칩의 이미지와 문구로 구분해요.
- 칸에 일정 제목을 길게 쓰지 않아요. 칩은 최대 80px이고 넘치면 말줄임으로 보여요. 제목은 날짜를 눌러 연 곳에서 보여 줘요.
- 날짜는 모두 `YYYY-MM-DD` 문자열이에요. `today`는 렌더 중 `new Date()`로 만들지 않고 서버에서 한 번 만들어 넘겨요.
- 오늘은 색만이 아니라 "오늘" 글자와 윗줄 굵기로도 구분돼요.
