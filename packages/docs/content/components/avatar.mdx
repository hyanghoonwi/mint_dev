## Examples

<ExampleTabs
  items={[
    { title: "이미지가 없을 때", name: "avatar/Basic" },
    { title: "브랜드", name: "avatar/Brand" },
    { title: "알림 배지", name: "avatar/Badge" },
    { title: "배지 크기", name: "avatar/BadgeSize" },
    { title: "눌리는 아바타", name: "avatar/Interactive" },
    { title: "글자 옆 16px", name: "avatar/Inline" },
    { title: "반응형", name: "avatar/Responsive" },
  ]}
/>

- **이미지가 없을 때**: `src`가 있으면 이미지, 없으면 `name`의 첫 글자, 둘 다 없으면 사용자 아이콘이 보여요. 이미지를 불러오는 동안이나 불러오지 못하면 회색 바탕만 보여요.
- **브랜드**: `variant="brand"`는 서비스·코인·조직처럼 사람이 아닌 대상에 쓰는 둥근 사각형이에요.
- **알림 배지**: 새 소식은 `badge="dot"`, 개수는 숫자로 줘요. 99를 넘으면 `99+`로 보여요.
- **배지 크기**: 배지 크기는 아바타 크기에 맞춰지고, `badgeSize`(`xs`~`xl`)로 따로 고를 수도 있어요. 배지 위치는 아바타 크기를 따라요.
- **눌리는 아바타**: `onClick`을 주면 버튼이 돼요. 눌러 보면 배지 숫자가 올라가요.
- **글자 옆 16px**: 작성자 이름이나 참여자 수 옆에는 `size={16}`을 써요. 작아서 누르는 용도로는 쓰지 않아요.
- **반응형**: `size`는 구간별 값도 받아요. `{ base: 32, tablet: 48 }`면 모바일은 32, 태블릿(768px)부터 48이고, 배지 위치와 크기도 함께 바뀌어요. 창 폭을 바꿔 보세요.

## Props

나머지 `<div>` 속성도 그대로 받아요.\
서버 컴포넌트에서 바로 쓸 수 있고, `onClick`을 넘길 때만 클라이언트 컴포넌트 안에서 써요.

| 이름       | 타입                                                                | 기본값     | 설명                                                              |
| ---------- | ------------------------------------------------------------------- | ---------- | ----------------------------------------------------------------- |
| `size`     | `16 \| 24 \| 32 \| 40 \| 48 \| 64` 또는 `{ base, tablet, desktop }` | `40`       | 지름(px). 객체로 주면 구간마다 달라지고 배지 위치·크기도 따라가요 |
| `variant`  | `"person" \| "brand"`                                               | `"person"` | 원형 또는 둥근 사각형                                             |
| `src`      | `string`                                                            | -          | 이미지 주소                                                       |
| `name`     | `string`                                                            | -          | 이름. 이미지가 없으면 첫 글자를 보여 주고, 스크린리더가 읽어요    |
| `icon`     | `ReactNode`                                                         | -          | `src`·`name`이 없을 때 보여 줄 아이콘(기본은 사용자 아이콘)       |
| `badge`    | `"dot" \| number`                                                   | -          | 알림 배지. 99를 넘으면 `99+`, 0 이하는 숨겨요                     |
| `disabled` | `boolean`                                                           | `false`    | 누를 수 없는 상태                                                 |
| `onClick`  | `(event) => void`                                                   | -          | 주면 눌리는 아바타(`<button>`)가 돼요                             |

## Guidelines

<AvatarGuide />

- 이미지가 없을 때를 항상 준비해요. `name`을 함께 주면 이미지가 없을 때 첫 글자로 대신해요.
- 같은 목록에서는 크기를 하나로 맞춰요. 목록에는 40, 상세 화면에는 64를 써요.
- 얼굴이 잘리는 이미지를 그대로 쓰지 않아요. 이미지는 가운데를 기준으로 꽉 채워 잘려요.
- 이미지나 아이콘만 쓰는 아바타도 `name`이나 `aria-label`로 스크린리더가 읽을 이름을 붙여요.
- 여러 명을 겹쳐 보여 줄 때는 [Avatar group](/components/avatar-group)을 써요.
