# Ratio bar

전체를 100%로 보고 여러 구간의 비율을 한 줄 막대로 보여 주는 컴포넌트예요. 도미넌스처럼 구간이 나뉘어 합이 100%가 될 때 써요.

    },
    {
      title: "범례·값",
      name: "ratio-bar/Options",
      style: { alignItems: "stretch" },
    },
    {
      title: "반응형",
      name: "ratio-bar/Responsive",
      style: { alignItems: "stretch" },
    },
  ]}
/>

- **기본**: 구간 이름과 퍼센트 값을 `items`로 넘겨요. 구간 폭은 값의 비율이고, 폭은 부모를 채워요.
- **구간 수**: 구간은 3\~5개예요. 구간 수마다 색 순서가 정해져 있고, 앞에서부터 진한 색이에요.
- **크기**: 막대 높이가 `lg` 32px · `md` 24px(기본) · `sm` 16px이에요. `sm`은 막대 안 값이 없어요.
- **범례·값**: `legend={false}`면 막대 위 범례를 끄고, `showValues={false}`면 막대 안 값을 숨겨요.
- **반응형**: `size`·`legend`·`showValues`는 구간별 값도 받아요. `size={{ base: "sm", tablet: "md", desktop: "lg" }}`면 모바일은 막대 16px, 태블릿(768px)부터 24px, 데스크톱(1024px)부터 32px이에요. `showValues={{ base: false, desktop: true }}`면 막대 안 값은 데스크톱에서만 보이고, 좁은 화면에서는 범례로 읽어요. 범례는 `legend={{ base: true }}`처럼 구간마다 켜고 끌 수 있어요. 창 폭을 바꿔 보세요.

## Props

나머지 `<div>` 속성도 그대로 받아요.\
서버 컴포넌트에서 바로 쓸 수 있어요.

| 이름             | 타입                                                    | 기본값 | 설명                                                                     |
| ---------------- | ------------------------------------------------------- | ------ | ------------------------------------------------------------------------ |
| `size`           | `"sm" \| "md" \| "lg"` 또는 `{ base, tablet, desktop }` | `"md"` | 막대 높이 16 · 24 · 32px. 객체로 주면 구간마다 달라져요                  |
| `items`          | `{ label: string, value: number }[]`                    | -      | 구간 목록(필수). 3\~5개. `value`는 퍼센트 숫자(`56.2`)예요               |
| `fractionDigits` | `number`                                                | -      | 값의 소수점 자릿수를 맞춰요(`1`이면 `9` → `9.0%`)                        |
| `legend`         | `boolean` 또는 `{ base, tablet, desktop }`              | `true` | 막대 위 범례(색 점 + 이름 + 값). 객체로 주면 구간마다 달라져요           |
| `showValues`     | `boolean` 또는 `{ base, tablet, desktop }`              | `true` | 막대 안에 값을 보여요. `sm`은 항상 숨어요. 객체로 주면 구간마다 달라져요 |

## Guidelines

<RatioBarGuide />

- 구간은 3\~5개로 써요. 색이 그 범위만 정해져 있어요.
- `value`는 퍼센트 숫자(`56.2`)로 넘기고 `%`는 컴포넌트가 붙여요. 자릿수가 섞이면 `fractionDigits`로 맞춰요.
- 색만으로 구간을 구분하지 않아요. 범례에 이름과 값을 함께 보여 줘요.
- 같은 화면에서는 크기를 하나로 맞춰요.
- 막대는 `div` 폭을 계산해 직접 만들지 않고 `RatioBar`를 써요.
- 그림 전체가 하나의 이미지처럼 읽혀요. 스크린리더에는 "비트코인 56.2%, 이더리움 11.8%, …"가 읽혀요.
