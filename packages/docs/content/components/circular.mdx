## Props

나머지 `<svg>` 속성도 그대로 받아요.\
서버 컴포넌트에서 바로 쓸 수 있어요.

| 이름    | 타입                                | 기본값      | 설명                                                    |
| ------- | ----------------------------------- | ----------- | ------------------------------------------------------- |
| `size`  | `number`                            | `28`        | 지름(px)                                                |
| `color` | `"default" \| "brand" \| "on-fill"` | `"default"` | 회색 · 브랜드색 · 진한 배경 위의 흰색                   |
| `label` | `string`                            | `"로딩 중"` | 스크린리더가 읽을 이름. 장식용이면 `aria-hidden`을 줘요 |

## Guidelines

<CircularGuide />

- 로드 시간이 짧은 일반적인 상황에 써요.
- 버튼의 로딩은 따로 그리지 않고 `Button`의 `loading`을 써요.
- 기본으로 `role="status"`와 이름(`로딩 중`)이 붙어서 스크린리더가 로딩 중인 걸 알 수 있어요. 다른 문구로 바꾸려면 `label`을 줘요.
- 이미 다른 문구가 있는 곳에서는 `aria-hidden`을 주고 부모가 상태를 알려요.
- 움직임 줄이기 설정을 켠 사용자에게는 회전이 멈춰요.
