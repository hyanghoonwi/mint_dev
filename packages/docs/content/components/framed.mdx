# Framed

여러 요소를 하나의 틀로 묶어서 관련 정보를 한 덩어리로 보여 주는 컴포넌트예요.

<ComponentBadges />

<Figure height={240} />

선택된 묶음은 테두리로 강조해요. 안쪽에는 [Checkbox](/components/checkbox), [Radio](/components/radio), Select Item 같은 내용을 넣어요.

|      | Framed                                | List Cell                 |
| ---- | ------------------------------------- | ------------------------- |
| 목적 | 관련 요소를 한 덩어리로 묶어 선택해요 | 목록의 한 줄을 보여 줘요  |
| 내용 | Checkbox, Radio, Select Item을 담아요 | 아이콘, 라벨, 값을 담아요 |
| 선택 | 선택된 틀이 테두리로 강조돼요         | 선택은 체크로 표시해요    |

내용에 따라 세 가지를 써요. `FramedCheckbox`·`FramedRadio`는 틀 어디를 눌러도 안의 컨트롤이 선택돼요.

| 컴포넌트         | 내용                      | 쓰는 곳                                    |
| ---------------- | ------------------------- | ------------------------------------------ |
| `FramedCheckbox` | 체크박스                  | 여러 개를 고를 때                          |
| `FramedRadio`    | 라디오                    | `RadioGroup` 안에서 하나만 고를 때         |
| `Framed`         | 다른 내용(Select Item 등) | 틀만 필요할 때. 선택은 `selected`로 넘겨요 |

## Examples

<ExampleTabs
  items={[
    { title: "하나만 고르기", name: "framed/Plan" },
    { title: "여러 개 고르기", name: "framed/Notifications" },
    { title: "오류", name: "framed/Error" },
    { title: "크기", name: "framed/Sizes" },
  ]}
/>

- **하나만 고르기**: `RadioGroup` 안에 `FramedRadio`를 넣어요. 틀 사이 간격은 `className="gap-2"`(8px)로 둬요.
- **여러 개 고르기**: `FramedCheckbox`를 나란히 둬요. `name`·`value`로 폼에 그대로 제출돼요.
- **오류**: 고르지 않고 넘어가면 `error`로 빨간 테두리를 보여 주고, 아래에 이유를 글로 알려요. 스크린리더에는 `aria-invalid`로 알려요.
- **크기**: 내용 양에 맞춰 `sm`·`md`·`lg`를 골라요. 띄워 보이게 하려면 `shadow`를 켜요.

## Props

`FramedCheckbox`·`FramedRadio`는 나머지 `<input>` 속성을, `Framed`는 나머지 `<div>` 속성을 받아요.\
클라이언트 컴포넌트라서 `onChange`는 클라이언트 컴포넌트 안에서 넘겨요.

| 이름                       | 타입                   | 기본값  | 설명                                                  |
| -------------------------- | ---------------------- | ------- | ----------------------------------------------------- |
| `size`                     | `"sm" \| "md" \| "lg"` | `"md"`  | 여백·모서리 12·8 · 16·12 · 20·16                      |
| `error`                    | `boolean`              | `false` | 오류 상태. 빨간 테두리로 보여 줘요                    |
| `shadow`                   | `boolean`              | `false` | 그림자로 띄워 보여요                                  |
| `label`                    | `ReactNode`            | -       | 레이블(필수). `Framed`는 `children`으로 내용을 넣어요 |
| `description`              | `ReactNode`            | -       | 레이블 아래 설명                                      |
| `checked`·`defaultChecked` | `boolean`              | -       | `FramedCheckbox`의 체크 여부                          |
| `indeterminate`            | `boolean`              | `false` | `FramedCheckbox`의 일부 선택                          |
| `value`                    | `string`               | -       | `FramedRadio`의 선택 값                               |
| `selected`                 | `boolean`              | `false` | `Framed`의 선택 표시. 컨트롤이 든 틀은 자동이에요     |
| `disabled`                 | `boolean`              | `false` | 누를 수 없는 상태(회색 바탕)                          |
| `onChange`                 | `(event) => void`      | -       | `FramedCheckbox`에서 체크가 바뀌면 불려요             |

## Guidelines

<FramedGuide />

- 설명이 긴 선택지를 카드처럼 나란히 보여 줄 때 써요.
- 같은 그룹에서는 크기와 내용을 통일해요.
- 틀 안에 틀을 중첩하지 않아요.
- 장식용 박스로 쓰지 않아요. 선택 의미가 있을 때만 써요.
- 선택은 테두리 색만이 아니라 안의 체크박스·라디오 표시로도 함께 알려요.
