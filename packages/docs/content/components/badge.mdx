## Examples

<ExampleTabs
  items={[
    { title: "강조(fill)", name: "badge/Fill" },
    { title: "부드럽게(weak)", name: "badge/Weak" },
    { title: "제목 옆", name: "badge/WithTitle" },
    { title: "목록 속 상태", name: "badge/InList" },
    { title: "반응형", name: "badge/Responsive" },
  ]}
/>

- **강조(fill)**: 진한 배경에 흰 글자로 가장 눈에 띄어요. 한 화면에 한두 개만 써서 강조해요(NEW, 마감).
- **부드럽게(weak)**: 연한 배경에 색 글자로 부드러워요. 카드나 목록 안에 여러 개가 나란히 있을 때 써요.
- **제목 옆**: 기본 크기(`md`)를 써요. 상세 화면 상단처럼 크게 보여야 하면 `lg`를 써요.
- **목록 속 상태**: 촘촘한 목록이나 카드 위에 겹칠 때는 `sm`을 써요. 같은 화면에서는 크기를 하나로 맞춰요.
- **반응형**: `size`는 구간별 값도 받아요. `{ base: "sm", tablet: "md" }`면 모바일은 20, 태블릿(768px)부터 24예요. 창 폭을 바꿔 보세요.

## Props

나머지 `<span>` 속성도 그대로 받아요.\
서버 컴포넌트에서 바로 쓸 수 있어요.

| 이름       | 타입                                                         | 기본값    | 설명                                               |
| ---------- | ------------------------------------------------------------ | --------- | -------------------------------------------------- |
| `variant`  | `"fill" \| "weak"`                                           | `"fill"`  | 진한 배경 또는 연한 배경                           |
| `color`    | `"brand" \| "neutral" \| "danger" \| "success" \| "warning"` | `"brand"` | 의미에 맞는 색                                     |
| `size`     | `"sm" \| "md" \| "lg"` 또는 `{ base, tablet, desktop }`      | `"md"`    | 높이 20 · 24 · 28px. 객체로 주면 구간마다 달라져요 |
| `children` | `ReactNode`                                                  | -         | 문구. 1\~4자로 짧게 써요                           |

## Guidelines

<BadgeGuide />

- 색은 의미로 골라요: `brand` 강조 · `neutral` 일반 · `danger` 오류·임박 · `success` 완료 · `warning` 주의.
- 글자는 1\~4자로 짧게 써요. 긴 문장은 넣지 않아요(Chip은 1\~8자).
- 색만으로 뜻을 전하지 않아요. 글자로도 상태를 적어서 색을 못 보는 사용자도 알 수 있게 해요.
- 표시 전용이라 눌러지는 요소처럼 보이지 않게 화살표나 아이콘을 붙이지 않아요.
