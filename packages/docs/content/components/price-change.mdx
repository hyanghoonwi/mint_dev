# Price change

가격이나 시세가 오르내린 정도를 화살표와 부호로 보여 주는 표시 전용 부품이에요.

## Playground

오른쪽에서 props를 바꾸면 등락 표시와 아래 코드가 함께 바뀌어요. 눌러도 아무 동작이 없는 표시 전용이고, 상태나 분류는 `Badge`가 알려요.

## Examples

<ExampleTabs
  items={[
    { title: "금액", name: "price-change/Amount" },
    { title: "퍼센트", name: "price-change/Percent" },
    { title: "연한 배경(weak)", name: "price-change/Weak" },
    { title: "시세 목록", name: "price-change/InList" },
    { title: "반응형", name: "price-change/Responsive" },
  ]}
/>

- **금액**: 금액에는 화살표만 붙어요. 오르면 빨강 ▲, 내리면 파랑 ▼, 변동이 없으면 회색 가로선이에요.
- **퍼센트**: `type="percent"`면 화살표 대신 부호(+, -)가 붙어요. 보합은 부호 없이 `0.00%`예요.
- **연한 배경(weak)**: 카드나 요약 영역에서 등락을 더 눈에 띄게 보여 줄 때 써요.
- **시세 목록**: 표나 목록에는 `sm`을 써요. 방향은 값의 부호로 정하고, 숫자는 절댓값을 넘겨요.
- **반응형**: `size`는 구간별 값도 받아요. `{ base: "sm", desktop: "md" }`면 모바일·태블릿은 12px, 데스크톱(1024px)부터 14px이에요. 창 폭을 바꿔 보세요.

## Props

나머지 `<span>` 속성도 그대로 받아요.\
서버 컴포넌트에서 바로 쓸 수 있어요.

| 이름        | 타입                                                    | 기본값     | 설명                                               |
| ----------- | ------------------------------------------------------- | ---------- | -------------------------------------------------- |
| `direction` | `"up" \| "down" \| "flat"`                              | -          | 상승 빨강 · 하락 파랑 · 보합 회색                  |
| `type`      | `"amount" \| "percent"`                                 | `"amount"` | 금액은 화살표, 퍼센트는 부호를 붙여요              |
| `variant`   | `"text" \| "weak"`                                      | `"text"`   | 글자만 또는 연한 배경                              |
| `size`      | `"sm" \| "md" \| "lg"` 또는 `{ base, tablet, desktop }` | `"md"`     | 글자 12 · 14 · 16px. 객체로 주면 구간마다 달라져요 |
| `children`  | `ReactNode`                                             | -          | 숫자만 넣어요(`1,200`, `3.42%`)                    |

## Guidelines

<PriceChangeGuide />

- 금액에는 화살표(▲ ▼)만, 퍼센트에는 부호(+, -)만 써요. 한 표시에 둘을 함께 쓰지 않아요.
- 숫자에 부호나 화살표를 직접 넣지 않아요. 방향은 `direction`으로 정해요.
- 소수점 둘째 자리까지 맞춰 써서 표 안에서 자릿수가 흔들리지 않게 해요.
- 크기는 `sm` 표·목록, `md` 기본, `lg` 요약 카드에 써요. 같은 목록에서는 크기를 하나로 맞춰요.
- 눌러서 동작하는 요소로 쓰지 않아요. 상태나 분류(NEW, 인기)는 `Badge`를 써요.
- 방향을 색만으로 알리지 않아요. 화살표와 부호가 함께 보이고, 스크린리더에는 "상승·하락·보합"이 읽혀요.
