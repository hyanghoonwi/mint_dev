## Examples

<ExampleTabs
  items={[
    { title: "아이콘과 함께", name: "button/WithIcon" },
    { title: "로딩", name: "button/Loading" },
    { title: "닫기 + 확인", name: "button/Pair" },
    {
      title: "전체 폭",
      name: "button/FullWidth",
      style: { maxWidth: 375, width: "100%" },
    },
    { title: "반응형", name: "button/Responsive", style: { width: "100%" } },
  ]}
/>

- **아이콘과 함께**: 앞 아이콘(`leftAddon`)은 행동의 의미를 보조할 때, 뒤 아이콘(`rightAddon`)은 동작의 방향이나 결과를 알릴 때 써요. 둘 다 넣을 수는 있지만 하나만 쓰는 걸 권장해요.
- **로딩**: 레이블 대신 진행 원이 보이고, 원 크기는 버튼 크기를 따라요. 버튼 크기는 그대로이고 중복 탭을 막아요.
- **닫기 + 확인**: 닫기·취소 같은 해제 동작은 `secondary`, 확인은 `solid`로 두고 폭을 3:7로 나눠요.
- **전체 폭**: `fullWidth`를 주면 부모 폭을 꽉 채워요. 모바일 하단 버튼에 써요.
- **반응형**: `size`와 `fullWidth`는 구간별 값도 받아요. `{ base: "lg", tablet: "md" }`처럼 주면 모바일은 `lg`, 태블릿(768px)부터 `md`예요. 빈 구간은 앞 구간 값을 이어받아요. 창 폭을 바꿔 보세요.

## Props

나머지 `<button>` 속성도 그대로 받아요.\
서버 컴포넌트에서 바로 쓸 수 있고, `onClick`을 넘길 때만 클라이언트 컴포넌트 안에서 써요.

| 이름         | 타입                                                            | 기본값      | 설명                                                                                  |
| ------------ | --------------------------------------------------------------- | ----------- | ------------------------------------------------------------------------------------- |
| `variant`    | `"solid" \| "outline" \| "ghost"`                               | `"solid"`   | 모양                                                                                  |
| `color`      | `"primary" \| "neutral" \| "secondary" \| "destructive"`        | `"primary"` | 색. `outline`은 `neutral`·`primary`, `ghost`는 `neutral`만 써요(둘 다 기본 `neutral`) |
| `size`       | `"xs" \| "sm" \| "md" \| "lg"` 또는 `{ base, tablet, desktop }` | `"md"`      | 높이 28 · 32 · 40 · 48px. 객체로 주면 구간마다 달라져요                               |
| `leftAddon`  | `ReactNode`                                                     | -           | 글자 앞 아이콘. `xs`에서는 그리지 않아요                                              |
| `rightAddon` | `ReactNode`                                                     | -           | 글자 뒤 아이콘                                                                        |
| `loading`    | `boolean`                                                       | `false`     | 진행 중. 레이블을 숨기고 누름을 막아요                                                |
| `disabled`   | `boolean`                                                       | `false`     | 누를 수 없는 상태                                                                     |
| `fullWidth`  | `boolean` 또는 `{ base, tablet, desktop }`                      | `false`     | 부모 폭을 꽉 채워요. 객체로 주면 구간마다 달라져요                                    |
| `type`       | `"button" \| "submit" \| "reset"`                               | `"button"`  | 폼 안에서 실수로 제출되지 않게 기본은 `button`이에요                                  |
| `onClick`    | `(event) => void`                                               | -           | 눌렀을 때                                                                             |

## Guidelines

<ButtonGuide />

- 강한 버튼(`solid`의 `primary`·`neutral`·`destructive`)은 화면에 하나만 써요. 일반 화면의 CTA는 `neutral`을 써요.
- `destructive`는 삭제처럼 되돌리기 어려운 행동에만 쓰고, 색뿐 아니라 글자로도 뜻을 알려요.
- 터치 화면에서 `xs`와 `sm`은 보이는 크기는 그대로 두고 눌림 영역만 44px로 넓어져요. `xs`는 모바일에서 되도록 쓰지 않아요.
- 아이콘만 필요하면 `Button` 대신 [`IconButton`](/components/icon-button)을 써요.
