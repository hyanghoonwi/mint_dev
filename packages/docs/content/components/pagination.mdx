# Pagination

많은 데이터를 여러 페이지로 나누어 보여 주는 페이지 이동 컨트롤이에요.

분량이 적으면 쓰지 않아요. 3\~4화면 이내라면 더 보기나 무한 스크롤을 써요.

|           | Pagination                             | 더 보기 / 무한 스크롤 |
| --------- | -------------------------------------- | --------------------- |
| 쓰는 곳   | 게시글, 목록처럼 양이 많은 데이터      | 짧은 목록, 피드       |
| 분량      | 4화면 넘는 분량                        | 3\~4화면 이내         |
| 위치 파악 | 현재 페이지가 몇 번째인지 알 수 있어요 | 알기 어려워요         |

- **버튼**: 화면 안에서 페이지를 바꾸면 `onChange`로 받아요. 클라이언트 컴포넌트에서 써요.
- **링크**: 주소의 `?page=`로 바꾸면 `getHref`를 줘요. Next.js에서는 `linkComponent={Link}`를 넘기고, 서버 컴포넌트에서 그대로 써요.
- **Extended · Compact**: 웹·태블릿은 9칸, 모바일은 7칸이에요. 기본값 `responsive`는 화면 폭에 따라 저절로 바뀌어요(768px 미만 compact).
- **처음과 끝**: 첫 페이지에서는 이전이, 마지막 페이지에서는 다음이 비활성이 돼요. 페이지가 적으면 번호를 모두 보여 줘요.

## Props

나머지 `<nav>` 속성도 그대로 받아요.\
서버 컴포넌트에서 바로 쓸 수 있고, `onChange`를 넘길 때만 클라이언트 컴포넌트 안에서 써요.

| 이름            | 타입                                      | 기본값         | 설명                                         |
| --------------- | ----------------------------------------- | -------------- | -------------------------------------------- |
| `variant`       | `"responsive" \| "extended" \| "compact"` | `"responsive"` | 화면 폭에 따라 · 9칸 · 7칸                   |
| `page`          | `number`                                  | -              | 현재 페이지(1부터, 필수)                     |
| `total`         | `number`                                  | -              | 전체 페이지 수(필수). 1 이하면 그리지 않아요 |
| `getHref`       | `(page: number) => string`                | -              | 링크로 쓸 때 주소를 만들어요                 |
| `linkComponent` | `ElementType`                             | `"a"`          | 링크 컴포넌트. Next.js는 `Link`를 넘겨요     |
| `aria-label`    | `string`                                  | `"페이지"`     | 묶음 이름                                    |
| `onChange`      | `(page: number) => void`                  | -              | 버튼으로 쓸 때 다른 페이지를 누르면 불려요   |

## Guidelines

<PaginationGuide />

- 현재 페이지는 진한 배경으로 표시해요.
- 첫 페이지에서는 이전, 마지막 페이지에서는 다음을 비활성으로 둬요. 저절로 바뀌어요.
- 모바일에서 Extended를 쓰지 않아요. 번호가 작아져 누르기 어려워요.
- 페이지가 1개뿐이면 보여 주지 않아요. `total`이 1 이하면 그리지 않아요.
- Figma는 480px에서 Compact로 바꾸지만, MINT는 태블릿 구간(768px)에서 바꿔요.
