# Tab

같은 화면에서 보는 내용(섹션)을 바꾸는 밑줄형 탭이에요.

## Playground

오른쪽에서 props를 바꾸면 미리보기와 아래 코드가 함께 바뀌어요. 탭을 누르면 선택이 바뀌고, 선택된 탭은 밑줄과 굵은 글자로 표시돼요.

## Examples

<ExampleTabs
  items={[
    { title: "섹션 전환", name: "tab/Sections" },
    { title: "뱃지", name: "tab/Badge" },
    { title: "이름 폭에 맞추기", name: "tab/Hug", style: { maxWidth: 360 } },
    { title: "반응형", name: "tab/Responsive" },
  ]}
/>

- **섹션 전환**: `value`와 `onChange`로 고른 값을 받아 같은 화면의 내용을 바꿔요.
- **뱃지**: 새 소식이 있는 탭에만 `badge`로 점을 켜요. 스크린리더는 "(새 소식)"으로 읽어요.
- **이름 폭에 맞추기**: `layout="hug"`면 탭이 이름 폭만큼만 차지해요. 6개이거나 이름이 길 때 쓰고, 넘치면 가로로 스크롤돼요. 마우스는 끌어서 넘길 수 있어요.
- **반응형**: `size`와 `layout`은 구간별 값도 받아요. 모바일은 크게 폭을 나누고, 태블릿부터 이름 폭이에요. 창 폭을 바꿔 보세요.

## Props

나머지 `<div>` 속성도 그대로 받아요.\
클라이언트 컴포넌트라서 `onChange`는 클라이언트 컴포넌트 안에서 넘겨요.

| 이름           | 타입                                                    | 기본값   | 설명                                                                             |
| -------------- | ------------------------------------------------------- | -------- | -------------------------------------------------------------------------------- |
| `size`         | `"sm" \| "md" \| "lg"` 또는 `{ base, tablet, desktop }` | `"lg"`   | 높이 32 · 40 · 48. 객체로 주면 구간마다 달라져요                                 |
| `layout`       | `"fill" \| "hug"` 또는 `{ base, tablet, desktop }`      | `"fill"` | fill은 폭을 똑같이 나누고(이름이 길면 가로 스크롤), hug는 이름 폭만큼만 차지해요 |
| `fade`         | `boolean`                                               | `true`   | 탭이 넘칠 때 스크롤할 쪽 가장자리에 그라데이션이 나타나요                        |
| `items`        | `{ value, label, badge?, disabled? }[]`                 | -        | 탭 목록. 2\~6개, 이름은 2\~6자로 써요                                            |
| `value`        | `string`                                                | -        | 선택된 값(제어)                                                                  |
| `defaultValue` | `string`                                                | 첫 탭    | 처음 선택 값(비제어)                                                             |
| `aria-label`   | `string`                                                | -        | 탭 묶음의 이름. 꼭 줘요                                                          |
| `onChange`     | `(value: string) => void`                               | -        | 다른 탭을 눌렀을 때 새 값으로 불려요                                             |

## Guidelines

<TabGuide />

- 항상 하나가 선택돼 있어야 해요. 선택 없음 상태를 만들지 않아요.
- 탭 이름은 2\~6자 명사로 짧고 분명하게 써요.
- 5개 이하는 `fill`, 6개이거나 이름이 길면 `hug`를 써요. `fill`도 이름이 안 들어가면 탭이 이름 폭을 지키고 가로로 스크롤돼요.
- 탭 안에 또 탭을 넣지 않아요.
- 탭으로 다른 페이지로 이동하지 않아요. 이동은 링크나 버튼을 써요.
- 목록을 거르거나 분류를 고르는 곳에는 Category를 써요.
- 묶음에 `aria-label`로 이름을 줘요. 키보드는 ←·→로 옆 탭을, Home·End로 처음·끝 탭을 골라요.
