## Examples

<ExampleTabs
  items={[
    { title: "넘칠 때 +N", name: "avatar-group/Overflow" },
    { title: "+N 글자 바꾸기", name: "avatar-group/Count" },
    { title: "작은 크기", name: "avatar-group/Small" },
    { title: "반응형", name: "avatar-group/Responsive" },
  ]}
/>

- **넘칠 때 +N**: `max`(기본 3)보다 많으면 나머지 수가 마지막 칸에 `+N`으로 보여요.
- **+N 글자 바꾸기**: 전체 인원을 따로 알 때는 `count`로 넘친 칸의 글자를 직접 정해요.
- **작은 크기**: 목록이나 카드 안에서는 24나 32를 써요.
- **반응형**: `size`는 구간별 값도 받아요. `{ base: 24, tablet: 40 }`면 모바일은 24, 태블릿(768px)부터 40이고, 겹치는 폭과 `+N` 칸도 함께 바뀌어요.

## Props

나머지 `<div>` 속성도 그대로 받아요.\
서버 컴포넌트에서 바로 쓸 수 있어요.

| 이름    | 타입                                                                | 기본값 | 설명                                                    |
| ------- | ------------------------------------------------------------------- | ------ | ------------------------------------------------------- |
| `size`  | `16 \| 24 \| 32 \| 40 \| 48 \| 64` 또는 `{ base, tablet, desktop }` | `40`   | 지름(px). 객체로 주면 구간마다 달라지고 겹침도 따라가요 |
| `items` | `{ src?, name?, icon? }[]`                                          | -      | 겹쳐 보여 줄 아바타들(필수)                             |
| `max`   | `number`                                                            | `3`    | 보여 줄 최대 개수. 넘치면 `+N`이 붙어요                 |
| `count` | `string`                                                            | -      | 넘친 칸의 글자를 직접 정해요                            |

## Guidelines

<AvatarGroupGuide />

- 5개 넘게 펼치지 않아요. 많으면 `max`로 줄이고 `+N`으로 보여 줘요.
- `aria-label`로 몇 명인지 알려 줘요(예: `참여자 5명`).
- 한 명만 보여 줄 때는 [Avatar](/components/avatar)를 써요.
