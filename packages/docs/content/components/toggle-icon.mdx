# Toggle icon

눌러서 켜고 끄는 아이콘이에요.

<ComponentBadges />

<Figure height={240} />

관심 코인, 좋아요, 북마크처럼 상태를 유지해요. 한 번 누르면 동작만 하는 아이콘은 [Icon button](/components/icon-button)을 써요.

|      | Toggle icon                  | Icon button           |
| ---- | ---------------------------- | --------------------- |
| 목적 | 켜고 끄는 상태를 유지해요    | 한 번 누르면 동작해요 |
| 모양 | 꺼지면 선, 켜지면 채움이에요 | 아이콘이 그대로예요   |
| 예시 | 관심 코인, 좋아요, 북마크    | 닫기, 더보기, 공유    |

- **관심 코인 목록**: 상태를 사용하는 쪽이 가지려면 `active`와 `onActiveChange`를 함께 넘겨요. 목록에는 `sm`을 써요.
- **아이콘**: `icon`에 선 모양 아이콘을 넘기면 켜질 때 같은 아이콘의 채움 모양으로 바뀌어요.
- **크기**: 기본은 `md`(40)이고, 카드 위는 `md`, 목록은 `sm`(32)을 써요. 높이는 Icon button과 같아요.
- **비활성**: 켜짐·꺼짐 모두 회색으로 바뀌고 누를 수 없어요.
- **반응형**: `size`는 구간별 값도 받아요. `{ base: "sm", desktop: "md" }`면 모바일·태블릿은 32, 데스크톱(1024px)부터 40이에요. 창 폭을 바꿔 보세요.

## Props

나머지 `<button>` 속성도 그대로 받아요.\
켜짐 상태를 다루는 클라이언트 컴포넌트지만, 서버 컴포넌트에서 `defaultActive`만 넘겨 바로 쓸 수 있어요.

| 이름             | 타입                                                            | 기본값  | 설명                                                      |
| ---------------- | --------------------------------------------------------------- | ------- | --------------------------------------------------------- |
| `size`           | `"xs" \| "sm" \| "md" \| "lg"` 또는 `{ base, tablet, desktop }` | `"md"`  | 지름 28 · 32 · 40 · 48. 객체로 주면 구간마다 달라져요     |
| `icon`           | `ReactElement`                                                  | -       | 아이콘(필수). 켜지면 같은 아이콘의 채움 모양으로 바뀌어요 |
| `activeIcon`     | `ReactNode`                                                     | -       | 켜졌을 때 따로 보여 줄 아이콘                             |
| `aria-label`     | `string`                                                        | -       | 이름(필수). 상태와 관계없이 같게 써요. 예: "관심 코인"    |
| `active`         | `boolean`                                                       | -       | 켜짐 상태. 넘기면 사용하는 쪽이 상태를 가져요             |
| `defaultActive`  | `boolean`                                                       | `false` | 처음 켜짐 상태                                            |
| `disabled`       | `boolean`                                                       | `false` | 누를 수 없는 상태                                         |
| `onActiveChange` | `(active: boolean) => void`                                     | -       | 눌러서 상태가 바뀔 때 새 값으로 불려요                    |

## Guidelines

<ToggleIconGuide />

- 꺼지면 선, 켜지면 채움으로 같은 아이콘의 모양만 바꿔요.
- 이름(`aria-label`)은 상태와 관계없이 같게 써요. 켜짐 여부는 스크린리더가 따로 읽어요.
- 한 번 누르면 끝나는 동작(닫기, 공유)에는 쓰지 않아요. Icon button을 써요.
- 카드 위는 `md`, 목록은 `sm`을 써요. `xs`·`sm`도 터치 화면에서는 눌림 영역이 44px로 넓어져요.
