# Label

입력 칸 위에 붙는 이름이에요.

<ComponentBadges />

<Figure height={240} />

Text Field, Textarea, Select, Form에서 조합해서 써요.\
Label은 무엇을 입력하는지 알려 주고, 입력 예시는 Placeholder가 맡아요.

|      | Label                       | Placeholder                         |
| ---- | --------------------------- | ----------------------------------- |
| 목적 | 입력할 내용의 이름을 알려요 | 입력 예시를 보여 줘요               |
| 모양 | 입력 칸 위의 굵은 글자      | 입력 칸 안의 회색 글자              |
| 위치 | 입력 칸 바로 위             | 입력 칸 안에 있고 입력하면 사라져요 |

## Examples

<ExampleTabs
  items={[
    { title: "입력 칸과 연결", name: "label/WithInput" },
    { title: "필수 표시", name: "label/Required" },
    { title: "도움말 아이콘", name: "label/HelpIcon" },
    { title: "비활성", name: "label/Disabled" },
    { title: "반응형", name: "label/Responsive" },
  ]}
/>

- **입력 칸과 연결**: `htmlFor`에 입력 칸의 `id`를 주면 라벨을 눌러도 입력 칸이 선택돼요.
- **필수 표시**: `required`면 글자 옆에 빨간 `*`가 붙어요. 스크린리더는 "(필수)"로 읽어요.
- **도움말 아이콘**: `helpIcon`을 켜면 물음표 아이콘이 붙어요. 누르면 설명이 나오게 하려면 `Tooltip`으로 감싼 버튼을 넘겨요.
- **비활성**: 입력 칸을 쓸 수 없을 때 `disabled`로 글자와 아이콘을 흐리게 해요.
- **반응형**: `size`는 구간별 값도 받아요. `{ base: "md", desktop: "lg" }`면 모바일·태블릿은 14, 데스크톱부터 16이에요. 창 폭을 바꿔 보세요.

## Props

나머지 `<div>` 속성도 그대로 받아요.\
서버 컴포넌트에서 바로 쓸 수 있어요.

| 이름       | 타입                                                    | 기본값  | 설명                                                               |
| ---------- | ------------------------------------------------------- | ------- | ------------------------------------------------------------------ |
| `size`     | `"sm" \| "md" \| "lg"` 또는 `{ base, tablet, desktop }` | `"md"`  | 글자 12 · 14 · 16. 객체로 주면 구간마다 달라져요                   |
| `children` | `ReactNode`                                             | -       | 라벨 글자. 명사로 짧게 써요                                        |
| `required` | `boolean`                                               | `false` | 글자 옆에 빨간 `*`를 붙여요                                        |
| `disabled` | `boolean`                                               | `false` | 글자와 아이콘을 흐리게 해요                                        |
| `helpIcon` | `boolean \| ReactNode`                                  | `false` | `true`면 물음표 아이콘, 요소를 주면 그 요소를 글자 오른쪽에 놓아요 |
| `htmlFor`  | `string`                                                | -       | 이어 줄 입력 칸의 `id`                                             |

## Guidelines

<LabelGuide />

- 이름, 휴대폰 번호처럼 명사로 짧게 써요.
- 입력 칸마다 Label을 붙여요. Placeholder만 있으면 입력하는 순간 무엇인지 알 수 없어요.
- 필수 입력일 때만 `required`를 켜요.
- 크기는 기본 `md`를 쓰고, 입력 칸 크기에 맞춰 `sm`·`lg`를 골라요.
- `htmlFor`로 입력 칸과 이어 둬요.
- 글자색을 임의로 바꾸지 않고 시맨틱 색만 써요.
