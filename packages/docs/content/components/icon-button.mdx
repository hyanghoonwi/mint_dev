# Icon button

아이콘만으로 특정 동작을 실행하는 원형 버튼이에요.

<ComponentBadges />

<Figure height={240} />

의미 전달이 약하므로 꼭 필요한 곳에만 쓰고 이름(`aria-label`)을 붙여요. 글자가 있는 버튼은 [Button](/components/button), 켜고 끄는 아이콘은 [Toggle icon](/components/toggle-icon)을 써요.

|        | Icon button                | Button                 | Toggle icon               |
| ------ | -------------------------- | ---------------------- | ------------------------- |
| 목적   | 아이콘으로 동작을 실행해요 | 글자로 동작을 실행해요 | 켜고 끄는 상태를 유지해요 |
| 예시   | 닫기, 더보기, 공유         | 확인, 제출, 삭제       | 관심 코인, 좋아요         |
| 레이블 | 없어요 (aria-label 필수)   | 있어요                 | 없어요 (aria-label 필수)  |

- **화면 상단**: 닫기·공유·더보기처럼 널리 알려진 아이콘을 `normal`로 둬요. 같은 줄에는 3개까지 둬요.
- **종류**: `normal`은 아이콘만, `background`는 회색 바탕, `outline`은 테두리, `solid`는 가장 강조해요.
- **크기**: 기본은 `md`(40)이고, 표나 촘촘한 목록은 `xs`(28)를 써요. 높이는 Button과 같아요.
- **반응형**: `size`는 구간별 값도 받아요. `{ base: "sm", tablet: "md" }`면 모바일은 32, 태블릿(768px)부터 40이에요. 창 폭을 바꿔 보세요.
- **뱃지**: 알림처럼 새 소식을 점으로 알려요. 스크린리더에는 이름 뒤에 "(새 소식)"이 붙어 읽혀요.

## Props

나머지 `<button>` 속성도 그대로 받아요.\
서버 컴포넌트에서 바로 쓸 수 있고, `onClick`을 넘길 때만 클라이언트 컴포넌트 안에서 써요.

| 이름         | 타입                                                            | 기본값     | 설명                                                  |
| ------------ | --------------------------------------------------------------- | ---------- | ----------------------------------------------------- |
| `variant`    | `"normal" \| "background" \| "outline" \| "solid"`              | `"normal"` | 배경 없음 · 회색 바탕 · 테두리 · 브랜드               |
| `size`       | `"xs" \| "sm" \| "md" \| "lg"` 또는 `{ base, tablet, desktop }` | `"md"`     | 지름 28 · 32 · 40 · 48. 객체로 주면 구간마다 달라져요 |
| `icon`       | `ReactNode`                                                     | -          | 아이콘(필수). 크기와 색은 버튼이 맞춰요               |
| `aria-label` | `string`                                                        | -          | 버튼 이름(필수). 예: "닫기"                           |
| `badge`      | `boolean`                                                       | `false`    | 오른쪽 위 빨간 점                                     |
| `disabled`   | `boolean`                                                       | `false`    | 누를 수 없는 상태                                     |
| `onClick`    | `(event) => void`                                               | -          | 눌렀을 때 불려요                                      |

## Guidelines

<IconButtonGuide />

- 닫기(X), 더보기(⋯)처럼 의미가 널리 알려진 아이콘을 써요.
- Tooltip이나 `aria-label`로 이름을 함께 제공해요.
- 의미가 모호한 아이콘만으로 중요한 동작을 맡기지 않아요. 글자가 있는 Button을 써요.
- 같은 줄에 Icon button을 4개 이상 늘어놓지 않아요. 더보기로 묶어요.
- 터치 영역은 44px 이상이에요. `xs`·`sm`도 터치 화면에서는 눌림 영역이 44px로 넓어져요.
