# Container · Grid

반응형 페이지 레이아웃을 만드는 컴포넌트입니다. 컬럼 수(모바일 4 · 태블릿 8 · 데스크톱 12), 칸 사이 간격과 여백(20px), 최대 폭(1440px)은 화면 폭에 맞게 알아서 바뀝니다. 서버 컴포넌트에서도 그대로 쓸 수 있습니다.

## 사용법

`Grid` 안에 `Grid.Item`을 놓고, `span`에 구간별로 차지할 컬럼 수를 넣습니다. 아래는 카드가 모바일에서 한 줄에 1개, 태블릿에서 2개, 데스크톱에서 4개 놓이는 예시입니다. 브라우저 창 폭을 바꿔 보세요.

<Example name="grid/Cards" style={{ display: "block" }} />

| 한 줄에 놓을 카드 수 (모바일 / 태블릿 / 데스크톱) | `span`                               |
| ------------------------------------------------- | ------------------------------------ |
| 1개 / 1개 / 1개                                   | 생략 (한 줄 전체)                    |
| 1개 / 2개 / 4개                                   | `{ base: 4, tablet: 4, desktop: 3 }` |
| 2개 / 4개 / 6개                                   | `{ base: 2, tablet: 2, desktop: 2 }` |

`tablet`을 생략하면 `base` 값을, `desktop`을 생략하면 `tablet`(없으면 `base`) 값을 따릅니다.

## 페이지 틀

`Container`로 감싸면 화면 좌우 여백과 최대 폭이 적용됩니다. 데스크톱에서는 왼쪽 3컬럼과 오른쪽 9컬럼, 태블릿과 모바일에서는 위아래로 쌓이는 틀입니다.

## Props

### Container

`<div>` 속성을 그대로 받습니다. 페이지에 한 번만 감쌉니다.

### Grid

`<div>` 속성을 그대로 받습니다. 컬럼 수와 간격은 화면 폭에 따라 자동으로 정해집니다.

### Grid.Item

| 이름        | 타입                                          | 기본값     | 설명                                                             |
| ----------- | --------------------------------------------- | ---------- | ---------------------------------------------------------------- |
| `span`      | `{ base: 1~4; tablet?: 1~8; desktop?: 1~12 }` | 한 줄 전체 | 구간별로 차지할 컬럼 수. 구간마다 넣을 수 있는 최댓값이 다릅니다 |
| `className` | `string`                                      | -          | 추가 클래스                                                      |
