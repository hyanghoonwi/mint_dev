# Category

같은 목록을 거르거나 분류를 고르는 칩 목록이에요.

<ComponentBadges />

<Figure height={240} />

한 번에 하나만 선택하고, 칩이 많으면 가로로 스크롤해요.\
화면 내용 자체가 바뀌면 Tab을, 목록을 거르면 Category를 써요.

|      | Category                           | Tab                             |
| ---- | ---------------------------------- | ------------------------------- |
| 목적 | 같은 목록을 거르거나 분류를 골라요 | 같은 화면의 내용(섹션)을 바꿔요 |
| 모양 | 칩                                 | 밑줄형                          |
| 개수 | 3\~7개, 넘치면 가로 스크롤         | 5개 이하는 Fill, 6개 이상은 Hug |
| 선택 | 한 번에 하나만 선택해요            | 항상 하나가 선택돼요            |

## Playground

오른쪽에서 props를 바꾸면 미리보기와 아래 코드가 함께 바뀌어요. 칩이 넘치면 스크롤할 쪽 가장자리에 그라데이션이 저절로 나타나요.

## Examples

<ExampleTabs
  items={[
    { title: "목록 거르기", name: "category/Filter" },
    { title: "넘칠 때", name: "category/Overflow" },
    { title: "회색 배경 위", name: "category/OnGray" },
    { title: "배지·아이콘", name: "category/BadgeIcon" },
    { title: "반응형", name: "category/Responsive" },
  ]}
/>

- **목록 거르기**: `value`와 `onChange`로 고른 분류를 받아 아래 목록을 걸러요. "전체" 칩의 값은 `"all"`이에요.
- **넘칠 때**: 칩이 폭을 넘으면 한 줄로 두고 가로로 스크롤해요. 손가락으로 밀거나 마우스로 끌어서 넘기고, 마우스를 놓으면 조금 더 미끄러지다 멈춰요. 스크롤할 칩이 남은 쪽에만 그라데이션이 보여요.
- **회색 배경 위**: 회색 배경 위에서는 `variant="outline"`을 써요. 촘촘한 영역은 `size="md"`예요.
- **반응형**: `size`는 구간별 값도 받아요. `{ base: "lg", desktop: "md" }`면 모바일·태블릿은 40, 데스크톱(1024px)부터 32예요. 창 폭을 바꿔 보세요.
- **배지·아이콘**: 칩마다 `icon`(글자 앞 아이콘)과 `badge`(새 소식 점)를 줄 수 있어요.

## Props

나머지 `<div>` 속성도 그대로 받아요.\
클라이언트 컴포넌트라서 `onChange`는 클라이언트 컴포넌트 안에서 넘겨요.

| 이름           | 타입                                            | 기본값     | 설명                                                                    |
| -------------- | ----------------------------------------------- | ---------- | ----------------------------------------------------------------------- |
| `variant`      | `"solid" \| "outline"`                          | `"solid"`  | 흰 화면 · 회색 배경 위                                                  |
| `size`         | `"lg" \| "md"` 또는 `{ base, tablet, desktop }` | `"lg"`     | 높이 40(모바일웹 기본) · 32(촘촘한 영역). 객체로 주면 구간마다 달라져요 |
| `shape`        | `"square" \| "pill"`                            | `"square"` | 둥근 사각형 · 알약형                                                    |
| `items`        | `{ value, label, icon?, badge?, disabled? }[]`  | -          | 칩 목록. 3\~7개를 권장해요                                              |
| `all`          | `boolean`                                       | `true`     | 맨 앞에 "전체" 칩(값 `"all"`)을 둬요                                    |
| `allLabel`     | `ReactNode`                                     | `"전체"`   | "전체" 칩 글자                                                          |
| `value`        | `string`                                        | -          | 선택된 값(제어)                                                         |
| `defaultValue` | `string`                                        | `"all"`    | 처음 선택 값(비제어). `all`을 끄면 첫 칩이에요                          |
| `fade`         | `boolean`                                       | `true`     | 넘칠 때 가장자리 그라데이션. 스크롤할 쪽에만 저절로 나타나요            |
| `aria-label`   | `string`                                        | -          | 칩 묶음의 이름. 꼭 줘요                                                 |
| `onChange`     | `(value: string) => void`                       | -          | 다른 칩을 눌렀을 때 새 값으로 불려요                                    |

## Guidelines

<CategoryGuide />

- 맨 앞에 "전체"를 두고 기본 선택으로 해요.
- 칩이 화면 폭을 넘으면 오른쪽 그라데이션으로 더 있다는 걸 알려요. `fade`를 켜 두면 저절로 나타나요.
- 칩을 두 줄로 줄바꿈하지 않아요. 한 줄로 두고 스크롤해요.
- 여러 개를 동시에 선택하게 하지 않아요. 복수 선택은 Checkbox를 써요.
- 흰 화면에서는 `solid`, 회색 배경 위에서는 `outline`을 써요.
- 선택된 칩은 배경과 글자 색 대비가 함께 바뀌어요. 색만으로 선택을 알리지 않아요.
- 칩 묶음에 `aria-label`로 이름을 줘요. 키보드는 ←·→로 옆 칩을, Home·End로 처음·끝 칩을 골라요.
