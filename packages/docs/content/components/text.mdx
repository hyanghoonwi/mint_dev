- **제목과 설명**: 모양(`variant`)과 태그(`as`)를 따로 골라요. 페이지 제목은 `as="h1"`, 설명은 `as="p"`예요.
- **색**: `color`는 시맨틱 글자색만 받아요. 기본은 `primary`예요. 감싼 요소의 색을 따라야 할 때만 `color="inherit"`을 줘요.
- **반응형 제목**: 큰 제목은 `variant`에 구간별 값을 줘요. 모바일은 Title 3(24px), 데스크톱(1024px)부터 Title 1(32px)이에요. 창 폭을 바꿔 보세요.
- **말줄임**: `lines`를 주면 그 줄 수를 넘는 글을 말줄임(…)으로 잘라요.

## Props

고른 태그의 나머지 속성도 그대로 받아요.\
서버 컴포넌트에서 바로 쓸 수 있어요.

| 이름       | 타입                                                                              | 기본값   | 설명                                               |
| ---------- | --------------------------------------------------------------------------------- | -------- | -------------------------------------------------- |
| `variant`  | `"title-1-bold" \| "body-2-regular" \| …` (59개) 또는 `{ base, tablet, desktop }` | -        | 텍스트 스타일(필수). 객체로 주면 구간마다 달라져요 |
| `color` | `"primary" \| "strong" \| "secondary" \| "tertiary" \| … \| "inherit"` | `"primary"` | 시맨틱 글자색. `"inherit"`이면 감싼 요소의 색을 따라요 |
| `children` | `ReactNode`                                                                       | -        | 글자                                               |
| `lines`    | `1 \| 2 \| 3 \| 4`                                                                | -        | 이 줄 수를 넘으면 말줄임                           |
| `as`       | `ElementType`                                                                     | `"span"` | 그릴 태그. `p`·`h1`\~`h6`·`label` 등               |

## Guidelines

<TextGuide />

- 역할에 맞는 스타일을 골라요. 본문은 Body 2가 기본이고, 버튼·칩 라벨은 Label(한 줄 전용)이에요.
- 제목처럼 보여도 문서 구조상 제목이 아니면 `as`를 `p`나 `span`으로 둬요. `h1`은 페이지에 하나만 둬요.
- 토큰에 없는 크기나 hex 색을 쓰지 않아요.
- 큰 제목은 구간마다 다른 스타일을 고를 수 있어요(`{ base: "title-3-bold", desktop: "title-1-bold" }`). 본문과 라벨은 화면 폭과 상관없이 같은 스타일을 써요.
- 표에 없는 크기(`text-[36px]`)는 쓰지 않아요.
- 색과 크기는 `className`이나 `style`로 바꾸지 않아요. `className`은 여백·정렬에만 써요.
