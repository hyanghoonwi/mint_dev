# Chip

필터나 카테고리처럼 선택 상태가 있는 알약형 요소예요.

<ComponentBadges />

<Figure height={240} />

행동을 실행하는 Button과 달리 값을 고르거나 조건을 바꿀 때 써요. 칩을 한 줄로 묶어 하나만 고르는 목록은 [Category](/components/category)를 써요.

|           | Chip                        | Button             |
| --------- | --------------------------- | ------------------ |
| 목적      | 값을 고르거나 조건을 바꿔요 | 행동을 실행해요    |
| 선택 상태 | Active로 선택 여부를 보여요 | 선택 상태가 없어요 |
| 예시      | 전체, 시그널, 에어드랍      | 확인, 제출, 삭제   |
| 개수      | 보통 2개 이상 묶어서 써요   | 단독으로 써도 돼요 |

## Examples

- **여러 개 고르기**: 누를 때마다 `active`를 켜고 꺼요. 개수는 `count`로 숫자를 보여 줘요.
- **하나만 고르기**: 기간처럼 하나만 고르면 `active`를 하나만 켜요. 넘치거나 "전체"가 필요하면 Category를 써요.
- **이미지**: `leadingImage`에 코인 로고 같은 `<img>`를 넘기면 둥글게 잘려 보여요. 회색 배경 위라서 `outline`을 썼어요.
- **크기**: 기본은 `md`(32)이고, 촘촘한 목록은 `sm`(28), 넉넉한 화면은 `lg`(40)를 써요.
- **반응형**: `size`는 구간별 값도 받아요. `{ base: "sm", tablet: "md" }`면 모바일은 28, 태블릿(768px)부터 32예요. 창 폭을 바꿔 보세요.

## Props

나머지 `<button>` 속성도 그대로 받아요.\
서버 컴포넌트에서 바로 쓸 수 있고, `onClick`을 넘길 때만 클라이언트 컴포넌트 안에서 써요.

| 이름           | 타입                                                    | 기본값     | 설명                                                |
| -------------- | ------------------------------------------------------- | ---------- | --------------------------------------------------- |
| `variant`      | `"solid" \| "outline"`                                  | `"solid"`  | 흰 화면 · 회색 배경 위                              |
| `size`         | `"lg" \| "md" \| "sm"` 또는 `{ base, tablet, desktop }` | `"md"`     | 높이 40 · 32 · 28. 객체로 주면 구간마다 달라져요    |
| `shape`        | `"square" \| "pill"`                                    | `"square"` | 둥근 사각형 · 알약형. 서비스 전체에서 하나로 맞춰요 |
| `children`     | `ReactNode`                                             | -          | 레이블. 8자를 넘기지 않아요                         |
| `leftAddon`    | `ReactNode`                                             | -          | 레이블 왼쪽 아이콘                                  |
| `rightAddon`   | `ReactNode`                                             | -          | 레이블 오른쪽 아이콘                                |
| `leadingImage` | `ReactNode`                                             | -          | 레이블 앞 둥근 이미지(`<img alt="" />`)             |
| `count`        | `ReactNode`                                             | -          | 레이블 뒤 개수                                      |
| `badge`        | `boolean`                                               | `false`    | 새 소식을 알리는 빨간 점                            |
| `active`       | `boolean`                                               | `false`    | 고른 상태. 스크린리더에는 `aria-pressed`로 알려요   |
| `disabled`     | `boolean`                                               | `false`    | 누를 수 없는 상태                                   |
| `onClick`      | `(event) => void`                                       | -          | 눌렀을 때 불려요. 여기서 `active`를 바꿔요          |

## Guidelines

<ChipGuide />

- 같은 줄의 Chip은 크기와 모양을 맞춰요.
- 하나만 고르는 필터는 선택(Active)을 하나만 켜요.
- 개수를 보여 줄 때는 Count를 써서 숫자로 알려요.
- 앞뒤 구성(아이콘·이미지·카운트)은 한 Chip에 하나만 붙여요.
- 레이블을 8자 넘게 써서 두 줄로 만들지 않아요.
- Chip으로 화면 이동이나 제출 같은 행동을 실행하지 않아요. Button을 써요.
- 선택 상태는 색만으로 알리지 않아요. 고른 칩은 배경과 글자 색이 함께 바뀌어요.
- 터치 영역은 44px 이상이에요. Small도 터치 화면에서는 눌림 영역이 44px로 넓어져요.
