# Alert

사용자가 꼭 확인하고 넘어가야 하는 상황에 쓰는 대화상자예요.

<ComponentBadges />

<Figure height={240} />

<Callout type="warning">
  **Alert는 [`useOverlay`](/utilities/use-overlay)와 함께 써요.** 열림
  상태(`useState`)와 Alert를 페이지마다 들고 있지 않고, 버튼의 `onClick`에서
  `overlay.open`으로 열면 돼요. 앱 최상단에 `OverlayProvider`가 있어야 해요.
</Callout>

- **useOverlay로 열기**: 권장하는 방법이에요. `overlay.open`으로 열고, 열림 상태를 따로 두지 않아요.
- **기본**: 제목에 상황을, 본문에 해결 방법을 적고, 취소 같은 보조 행동은 앞에, 주된 행동은 오른쪽 끝에 둬요.
- **되돌릴 수 없는 일**: 삭제·탈퇴처럼 되돌리기 어려운 일은 주된 버튼을 `color="destructive"`로 알려요.
- **제목 없이**: 본문만으로 충분하면 `heading`을 빼요.
- **버튼 하나**: 알리기만 하면 되는 상황은 버튼 하나로 닫아요.

## Props

나머지 `<dialog>` 속성도 그대로 받아요.\
클라이언트 컴포넌트예요. `useOverlay`로 열면 `open`·`onClose`에 `isOpen`·`close`를 넘기고, `<Alert ... />`처럼 자식 없이 써요.

| 이름      | 타입         | 기본값 | 설명                                                              |
| --------- | ------------ | ------ | ----------------------------------------------------------------- |
| `open`    | `boolean`    | -      | 열림 여부(필수)                                                   |
| `heading` | `ReactNode`  | -      | 한 줄로 요약한 제목. 없으면 제목 줄이 사라져요                    |
| `body`    | `ReactNode`  | -      | 본문. 해결 방법을 적어요(필수)                                    |
| `action`  | `ReactNode`  | -      | 하단 버튼 영역(필수). `Button`을 1\~2개 넣으면 오른쪽 끝에 놓여요 |
| `onClose` | `() => void` | -      | <kbd>Esc</kbd>를 눌렀을 때. 여기서 `open`을 `false`로 바꿔요      |

## Guidelines

<AlertGuide />

- 흐름을 멈추고 확인을 받을 때만 써요. 정보만 알리는 일에는 Toast나 Snackbar를 써요.
- 제목에는 상황을, 본문에는 해결 방법을 적어요. 본문에 버튼·입력창 같은 조작 요소는 넣지 않아요.
- 버튼은 1\~2개예요. 버튼을 눌러 닫는 건 각 버튼의 `onClick`에서 `open`을 바꿔서 해요.
- <kbd>Tab</kbd>으로 버튼을 옮기고 <kbd>Enter</kbd>로 실행하고 <kbd>Esc</kbd>로
  닫아요. 열리면 포커스가 안으로 들어가고, 닫히면 원래 자리로 돌아가요.
