<ExampleTabs
  items={[

    },
    { title: "크기", name: "tooltip/Sizes", style: { paddingBlock: 56 } },

- **아이콘 버튼 이름**: 아이콘만 있는 버튼에 이름을 알려 줘요. 마우스를 올리거나 <kbd>Tab</kbd>으로 포커스해 보세요. <kbd>Esc</kbd>를 누르면 닫혀요.
- **단축키**: 이름 대신 단축키 글자만 넣어요(`label="⌘C"`).
- **위치**: `top` · `bottom` · `left` · `right` 중 화면 가장자리를 피해 가장 잘 보이는 쪽을 골라요. 자동으로 뒤집히지 않아요.
- **화살표 정렬**: 화살표 끝이 대상의 가운데를 가리켜요. 대상이 화면 가장자리에 있으면 `start`나 `end`로 말풍선을 안쪽으로 펼쳐요.
- **크기**: 높이 30 · 36 · 42px이에요. 기본은 `md`예요.
- **반응형**: `position`과 `size`는 구간별 값도 받아요. `{ base: "bottom", desktop: "right" }`면 모바일·태블릿은 아래, 데스크톱(1024px)부터 오른쪽이에요. 창 폭을 바꿔 보세요.

## Props

나머지 `<span>` 속성도 그대로 받아요(대상을 감싸는 요소).\
서버 컴포넌트에서 import해도 되고, 열림 상태는 안에서 관리해요.

| 이름           | 타입                                                                      | 기본값     | 설명                                                            |
| -------------- | ------------------------------------------------------------------------- | ---------- | --------------------------------------------------------------- |
| `size`         | `"sm" \| "md" \| "lg"` 또는 `{ base, tablet, desktop }`                   | `"md"`     | 높이 30 · 36 · 42px. 객체로 주면 구간마다 달라져요              |
| `position`     | `"top" \| "bottom" \| "left" \| "right"` 또는 `{ base, tablet, desktop }` | `"top"`    | 대상 기준 위치. 객체로 주면 구간마다 달라져요                   |
| `arrowAlign`   | `"start" \| "center" \| "end"`                                            | `"center"` | 화살표 위치. 위·아래면 왼쪽·오른쪽, 왼쪽·오른쪽이면 위·아래예요 |
| `label`        | `ReactNode`                                                               | -          | 말풍선 글자. 한 줄로 짧게 써요                                  |
| `children`     | `ReactElement`                                                            | -          | 대상 요소 하나(버튼·링크)                                       |
| `open`         | `boolean`                                                                 | -          | 열림을 직접 정할 때. 생략하면 hover·포커스로 열려요             |
| `onOpenChange` | `(open: boolean) => void`                                                 | -          | 열림이 바뀔 때                                                  |

## Guidelines

<TooltipGuide />

- 이름이나 단축키처럼 짧은 보조 정보를 한 줄로 써요.
- 아이콘만 있는 버튼에 이름을 알려 줘요. 버튼의 `aria-label`도 따로 붙여요.
- Hover뿐 아니라 키보드 포커스에서도 열려요. 스크린리더는 대상과 함께 말풍선 글자를 읽어요.
- Tooltip 안에 링크나 버튼을 넣지 않아요.
- 반드시 읽어야 하는 안내를 Tooltip에만 두지 않아요. 터치 화면에는 hover가 없어서 보이지 않을 수 있어요.
- 행동 결과를 알릴 때는 Tooltip이 아니라 Toast를 써요.
