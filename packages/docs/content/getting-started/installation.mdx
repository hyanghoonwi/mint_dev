# Installation

CryptoLab Design System을 Next.js 프로젝트에 설치하고 첫 화면을 만드는 방법이에요.\
세 단계면 돼요. 패키지를 설치하고, 스타일을 한 번 불러오고, 컴포넌트를 가져다 써요.

## Install

이 디자인 시스템은 사내 패키지(GitHub Packages)예요. 프로젝트 루트의 `.npmrc`에 아래 두 줄을 넣어요.

```bash filename=".npmrc"
@futurewiz-rms:registry=https://npm.pkg.github.com
//npm.pkg.github.com/:_authToken=${GITHUB_PACKAGES_TOKEN}
```

`GITHUB_PACKAGES_TOKEN`은 각자 GitHub에서 발급한 개인 액세스 토큰(`read:packages` 권한)이에요. 토큰 값은 파일에 직접 쓰지 않고 환경 변수로 둬요. 그다음 패키지를 설치해요.

```bash
npm install @futurewiz-rms/mint
```

## Styles

앱 최상단(`app/layout.tsx`)에서 스타일을 한 번 불러와요. 색, 글꼴, 간격 클래스가 모두 들어 있어서 Tailwind 설정이 없어도 돼요.

```tsx filename="app/layout.tsx"
import "@futurewiz-rms/mint/style.css";

export default function RootLayout({
  children,
}: {
  children: React.ReactNode;
}) {
  return (
    <html lang="ko">
      <body>{children}</body>
    </html>
  );
}
```

스타일을 불러오면 스크롤바도 디자인 시스템의 모양(8px, 가는 회색 손잡이)으로 바뀌어요. macOS에서도 스크롤바가 늘 보여요. 목록·Textarea·Modal처럼 스크롤되는 곳에 저절로 적용되니 따로 꾸미지 않아요. Chrome·Edge·Safari는 디자인과 같고, Firefox는 굵기와 색만 같아요.

지원 브라우저는 Chrome·Edge 111 이상, Safari 16.4 이상, Firefox 128 이상이에요.

[`useOverlay`](/utilities/use-overlay)로 Alert를 열려면 같은 자리에서 `OverlayProvider`로 한 번 감싸요. 다른 컴포넌트는 Provider가 필요 없어요.

## First page

컴포넌트를 가져와 써요. 서버 컴포넌트에서 바로 import해도 돼요.

```tsx filename="app/page.tsx"
import { Button, Container, Grid, Text } from "@futurewiz-rms/mint";

export default function Page() {
  return (
    <Container>
      <Grid>
        <Grid.Item span={{ base: 4, tablet: 4, desktop: 3 }}>
          <Text as="h1" variant="title-2-bold">
            오늘의 시세
          </Text>
          <Button fullWidth>시세 보기</Button>
        </Grid.Item>
      </Grid>
    </Container>
  );
}
```

`onClick`처럼 함수를 넘기는 부분은 클라이언트 컴포넌트(`"use client"`) 안에서 써요.
