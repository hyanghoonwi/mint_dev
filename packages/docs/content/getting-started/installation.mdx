# 설치

MINT는 React 컴포넌트와 디자인 토큰을 담은 패키지입니다. 세 단계로 Next.js 프로젝트에 적용할 수 있습니다.

## 1. 설치

사내 패키지(GitHub Packages)입니다. 프로젝트 루트의 `.npmrc`에 아래 두 줄을 넣고 설치합니다.

```bash filename=".npmrc"
@futurewiz-rms:registry=https://npm.pkg.github.com
//npm.pkg.github.com/:_authToken=${GITHUB_PACKAGES_TOKEN}
```

```bash
npm install @futurewiz-rms/mint
```

`GITHUB_PACKAGES_TOKEN`은 각자 GitHub에서 발급한 개인 액세스 토큰(`read:packages` 권한)입니다. 토큰 값은 파일에 직접 쓰지 않고 환경 변수로 둡니다.

## 2. 스타일 불러오기

앱 최상단에서 스타일을 한 번 불러옵니다. 색, 글꼴, 간격 클래스가 모두 들어 있어서 Tailwind 설정이 없어도 됩니다.

```tsx filename="app/layout.tsx"
import "@futurewiz-rms/mint/style.css";

export default function RootLayout({
  children,
}: {
  children: React.ReactNode;
}) {
  return (
    <html lang="ko">
      <body>{children}</body>
    </html>
  );
}
```

## 3. 첫 화면

컴포넌트를 가져와 씁니다. 서버 컴포넌트에서 바로 import해도 됩니다.

```tsx filename="app/page.tsx"
import { Button, Container, Grid } from "@futurewiz-rms/mint";

export default function Page() {
  return (
    <Container>
      <Grid>
        <Grid.Item span={{ base: 4, tablet: 4, desktop: 3 }}>
          <h1 className="text-title-2-bold">오늘의 시세</h1>
          <Button fullWidth>시세 보기</Button>
        </Grid.Item>
      </Grid>
    </Container>
  );
}
```

`onClick`처럼 함수를 넘기는 부분은 클라이언트 컴포넌트(`"use client"`) 안에서 씁니다.
