# 소개

MINT는 크립토랩의 디자인 시스템입니다. 시세와 차트, 커뮤니티를 만드는 데 필요한 파운데이션과 컴포넌트를 한곳에 모았고, 반응형 웹(모바일웹 ~ PC)에서 같은 컴포넌트를 씁니다.

<Figure height={260} />

## What is MINT

MINT는 같은 틀로 코인을 찍어 내는 조폐소처럼, 같은 컴포넌트로 화면을 만듭니다. Figma의 디자인과 React 컴포넌트가 같은 이름과 같은 값을 쓰기 때문에, 디자인과 개발이 같은 언어로 이야기할 수 있습니다.

## Getting Started

디자이너와 개발자가 같은 컴포넌트로 일관된 화면을 빠르게 만들 수 있도록, 기본 규칙이 정해진 컴포넌트를 제공합니다.

**처음 쓰는 분을 위한 안내**

- [설치](/getting-started/installation)에서 패키지를 설치하고 스타일을 불러옵니다.
- [Foundations](/foundations/overview)에서 색, 글자, 간격, 아이콘을 확인합니다.
- [Components](/components/overview)에서 쓰려는 컴포넌트의 사용법과 Props를 확인합니다.
- 필요한 스펙이나 여러 곳에서 쓸 것 같은 부분이 보이면 디자인 시스템 담당자에게 알려 주세요.
