# Introduction

MINT는 크립토랩 서비스의 화면을 만드는 디자인 시스템이에요.

<Figure height={260} />

시세·차트·커뮤니티 화면에 필요한 파운데이션과 컴포넌트를 한곳에 모았어요.\
반응형 웹(모바일웹 \~ PC)에서 같은 컴포넌트를 써요.

## What is MINT

같은 틀로 코인을 찍어 내는 조폐소처럼, MINT는 같은 컴포넌트로 화면을 만들어요. Figma 디자인과 React 컴포넌트가 같은 이름과 같은 값을 써서, 디자인과 개발이 같은 언어로 이야기할 수 있어요.

## Getting started

처음 쓴다면 아래 순서로 살펴보세요.

1. [Installation](/getting-started/installation)에서 패키지를 설치하고 스타일을 불러와요.
2. [Foundations](/foundations/overview)에서 색, 글자, 간격, 아이콘을 확인해요.
3. [Components](/components/overview)에서 쓰려는 컴포넌트의 사용법과 Props를 확인해요.
4. [Utilities](/utilities/overview)에서 자주 쓰는 훅을 확인해요.

필요한 스펙이 없거나 여러 곳에서 쓸 것 같은 화면이 보이면 디자인 시스템 담당자에게 알려 주세요.
