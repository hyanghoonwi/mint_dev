# 컬러

화면에는 역할 이름이 붙은 시맨틱 컬러를 씁니다. 시맨틱 컬러는 아토믹 컬러를 가리키는 별칭이고, 용도에 맞는 이름을 골라 클래스로 씁니다.

## 시맨틱 컬러

<Callout type="warning">
  **Light 모드만 있고, 브랜드 색은 임시입니다** 다크 모드 값은 디자인에 아직
  없습니다. 브랜드(`brand`) 색은 임시로 파랑(`blue-600`)이며, 브랜드 컬러가
  확정되면 이름은 그대로 두고 값만 바뀝니다.
</Callout>

분류는 다섯 가지입니다. 이름은 `<분류>-<이름>`이고, 클래스는 분류에 맞는 접두어(`bg-` `text-` `border-`)를 앞에 붙입니다.

| 분류         | 쓰는 곳                                  | 클래스 예                                      |
| ------------ | ---------------------------------------- | ---------------------------------------------- |
| `background` | 화면과 영역의 바탕                       | `bg-background-default` `bg-background-lower`  |
| `border`     | 구분선, 테두리, 포커스                   | `border-border-default` `border-border-strong` |
| `text`       | 글자                                     | `text-text-primary` `text-text-brand`          |
| `fill`       | 버튼·칩·배지 같은 면 (기본·weak·pressed) | `bg-fill-brand` `bg-fill-brand-weak`           |
| `icon`       | 아이콘 (글자색을 따라감)                 | `text-icon-default` `text-icon-brand`          |

<SemanticColors />

```tsx
<div className="rounded-12 border border-border-default bg-background-default p-5">
  <p className="text-body-2-medium text-text-primary">비트코인</p>
  <p className="text-caption-1-regular text-text-tertiary">
    2026-10-28 업데이트
  </p>
</div>
```

- 글자는 `strong` → `primary` → `secondary` → `tertiary` → `subtle` 순으로 약해집니다. 본문에는 `tertiary` 이상만 씁니다(`subtle` 이하는 대비가 낮아 플레이스홀더·힌트용).
- 채움 배경(`fill-*`) 위의 글자와 아이콘은 `text-text-on-fill`, `text-icon-on-fill`을 씁니다. 경고 채움(`fill-warning`) 위에서는 `text-text-on-fill-warning`입니다.
- 같은 의미의 면은 기본 → `-weak`(옅은 배경) → `-pressed`(눌림)로 나뉩니다. 배경이 없는 요소가 눌릴 때는 `bg-fill-pressed`를 위에 덮습니다.
- hex 값을 직접 쓰지 않습니다.

## 아토믹 컬러

Figma의 `Atomic` 변수와 같은 원시 색입니다. 값이 고정이라, 시맨틱 컬러로 표현할 수 없는 곳에만 씁니다.

```tsx
<div style={{ color: "var(--color-atomic-blue-500)" }}>…</div>
```

이름은 Figma에서 본 그대로 `var(--color-atomic-<이름>)`에 넣습니다. 아래 색 외에 `white`, `black`, 투명도만 다른 회색 `grayAlpha-50`~`900`이 있습니다.
