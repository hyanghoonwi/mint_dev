# Colors

역할 이름이 붙은 색으로 화면의 색을 일관되게 맞춰요.

<Callout type="warning">
  **지금은 Light 모드만 있고, 브랜드 색은 임시예요.** 다크 모드 값은 디자인에
  아직 없어요. 브랜드(`brand`) 색은 임시로 파랑(`blue-600`)이고, 정해지면 이름은
  그대로 두고 값만 바뀌어요.
</Callout>

## Usage

색은 두 단계예요. 값만 정한 원시 팔레트가 아토믹 컬러이고, 여기에 역할 이름을 붙인 것이 시맨틱 컬러예요. 화면에는 시맨틱 컬러를 클래스로 써요.

| 분류         | 쓰는 곳                                  | 클래스 예                                      |
| ------------ | ---------------------------------------- | ---------------------------------------------- |
| `background` | 화면과 영역의 바탕                       | `bg-background-default` `bg-background-lower`  |
| `border`     | 구분선, 테두리, 포커스                   | `border-border-default` `border-border-strong` |
| `text`       | 글자                                     | `text-text-primary` `text-text-brand`          |
| `fill`       | 버튼·칩·배지 같은 면 (기본·weak·pressed) | `bg-fill-brand` `bg-fill-brand-weak`           |
| `icon`       | 아이콘 (글자 색 클래스로 씀)             | `text-icon-default` `text-icon-brand`          |

클래스 이름은 `<접두어>-<분류>-<이름>`이에요. 글자 색은 [`Text`](/components/text)의 `color`로 정하고, 바탕·테두리는 클래스로 써요.

```tsx
import { Text } from "@futurewiz-rms/mint";

<div className="rounded-12 border border-border-default bg-background-default p-5">
  <Text as="p" variant="body-2-medium">
    비트코인
  </Text>
  <Text as="p" variant="caption-1-regular" color="tertiary">
    2026-10-28 업데이트
  </Text>
</div>;
```

시맨틱 컬러로 나타낼 수 없는 곳에만 아토믹 컬러를 CSS 변수로 써요.

```tsx
<div style={{ color: "var(--color-atomic-blue-500)" }}>…</div>
```

## Palette

탭을 눌러 두 단계의 색을 오가며 볼 수 있어요.

- **Semantic**: 실제로 쓰는 클래스, 값, 가리키는 아토믹 컬러와 용도예요.
- **Atomic**: 분류별 견본과 CSS 변수 목록이에요. 대비는 흰 배경 위에 그 색 글자를 올렸을 때의 비율이에요.

## Guidelines

- 화면에는 시맨틱 컬러를 써요. hex 값을 직접 쓰지 않아요.
- 글자는 `strong` → `primary` → `secondary` → `tertiary` → `subtle` 순으로 약해져요. 본문에는 `tertiary`까지만 쓰고, `subtle` 이하는 플레이스홀더·힌트에만 써요.
- 채움 배경(`fill-*`) 위의 글자와 아이콘은 `on-fill`을 써요. 경고 채움(`fill-warning`) 위에서는 `text-text-on-fill-warning`을 써요.
- 같은 의미의 면은 기본 → `-weak`(옅은 배경) → `-pressed`(눌림)로 나뉘어요. 배경이 없는 요소가 눌릴 때는 `bg-fill-pressed`를 위에 덮어요.
- 색만으로 의미를 전하지 않아요. 오류·성공은 글자나 아이콘을 함께 보여 줘요.
