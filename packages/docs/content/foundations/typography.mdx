# 타이포그래피

Pretendard 기반의 역할별 글자 스타일입니다. 클래스 하나로 크기, 줄 간격, 자간, 웨이트가 함께 정해집니다.

## 사용법

<Example
  name="typography/Usage"
  style={{ flexDirection: "column", alignItems: "flex-start", gap: 8 }}
/>

클래스 이름은 `text-<역할>-<번호>-<웨이트>`입니다. 번호는 1이 가장 큽니다. 크기·웨이트를 따로 붙이지 않습니다(`font-bold`, `text-[15px]` 없이 씁니다).

## 스타일

이름 · 크기/줄 간격(px), 보기 문장, 쓸 수 있는 웨이트입니다. 목록에 없는 조합(예: `text-display-1-regular`)은 없습니다.

<TypeScale />

## 역할별 용도

| 역할      | 용도                                                                 |
| --------- | -------------------------------------------------------------------- |
| `display` | 랜딩, 히어로 등 가장 큰 문구. 한 화면에 하나만 씁니다                |
| `title`   | 페이지 제목, 큰 섹션 제목                                            |
| `heading` | 섹션, 카드, 모달 제목                                                |
| `body-1`  | 아티클처럼 읽기 중심의 긴 글                                         |
| `body-2`  | 기본 본문                                                            |
| `body-3`  | 카드, 리스트의 설명 문구                                             |
| `body-4`  | 밀도 높은 UI, 표                                                     |
| `body-5`  | 보조 본문                                                            |
| `label`   | 버튼, 탭, 칩, 입력 라벨. 한 줄 전용이고, 두 줄이 될 수 있으면 `body` |
| `caption` | 날짜, 도움말, 각주                                                   |

## 원칙

- **글자 크기는 화면 폭에 따라 바뀌지 않습니다.** 반응형은 [그리드](/foundations/grid)의 컬럼 수와 여백으로 맞춥니다.
- 글꼴은 Pretendard 하나로 한글, 영문, 숫자를 모두 씁니다. 불러오지 못하면 기기 기본 글꼴로 보입니다.
