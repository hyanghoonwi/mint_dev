# Typography

하나의 글자 크기 표로 화면의 글자를 읽기 쉽고 일관되게 맞춰요.

## Typeface

글꼴은 Pretendard 하나예요. 제목부터 본문까지 한글, 영문, 숫자를 모두 같은 글꼴로 써요.

## Styles

역할마다 크기 단계와 쓸 수 있는 굵기가 정해져 있어요. 크기와 줄 간격은 화면 크기와 관계없이 하나의 표를 써요. 굵기 이름 아래에 `Text`의 `variant` 값이 있어요.

## Usage

글자는 [`Text`](/components/text)로 그려요. `variant` 하나로 크기, 줄 간격, 자간, 굵기가 함께 정해져요.

스타일 이름은 `<역할>-<번호>-<굵기>`예요. 번호는 1이 가장 커요. 컴포넌트를 쓸 수 없는 곳에서는 같은 이름의 클래스(`text-body-2-regular`)를 써요.

## Guidelines

- 크기 표는 하나예요. 모바일용·PC용 크기를 따로 만들지 않아요.
- 큰 제목만 구간마다 표 안의 다른 스타일을 골라요: `variant={{ base: "title-3-bold", desktop: "title-1-bold" }}`. 본문·라벨은 구간마다 바꾸지 않아요.
- 크기·굵기를 따로 붙이지 않아요(`font-bold`, `text-[15px]` 없이 써요).
- 목록에 없는 조합(예: `display-1-regular`)은 없어요.
- Pretendard를 불러오지 못하면 기기 기본 글꼴로 보여요.
