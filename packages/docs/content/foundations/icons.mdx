## 접근성

아이콘은 기본적으로 장식용이라 스크린 리더가 읽지 않습니다. 아이콘만으로 뜻을 전하는 곳에는 `aria-label`을 줍니다.

## 이름 규칙

Figma의 아이콘 이름을 PascalCase로 바꾸고 `Icon`을 붙입니다.

| Figma 이름         | 컴포넌트              |
| ------------------ | --------------------- |
| `arrow-left`       | `ArrowLeftIcon`       |
| `magnifying-glass` | `MagnifyingGlassIcon` |
| `x`                | `XIcon`               |

## 전체 아이콘

이름으로 찾고, 선·채움을 바꿔 볼 수 있습니다. 아이콘을 누르면 컴포넌트 이름이 복사됩니다.

## Props

| Prop         | 타입               | 기본값   | 설명                                         |
| ------------ | ------------------ | -------- | -------------------------------------------- |
| `size`       | `16 \| 20 \| 24`   | `24`     | 크기(px)                                     |
| `variant`    | `"line" \| "fill"` | `"line"` | 선 또는 채움                                 |
| `aria-label` | `string`           | -        | 아이콘만으로 뜻을 전할 때 읽힐 이름          |
| `className`  | `string`           | -        | 추가 클래스. 색은 글자색 클래스로 지정합니다 |

나머지 `<svg>` 속성도 그대로 받습니다. 아이콘 도형은 [Phosphor Icons](https://phosphoricons.com)(MIT)입니다.
