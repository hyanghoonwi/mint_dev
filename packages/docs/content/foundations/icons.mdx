# Icons

아이콘 183개를 컴포넌트로 바로 가져다 써요. 쓰는 아이콘만 앱에 들어가고, 서버 컴포넌트에서도 그대로 써요.

## Examples

  items={[

    { title: "이름 붙이기", name: "icon/Label" },
    { title: "버튼 안", name: "icon/WithButton" },
  ]}
/>

- **크기**: `size`는 `16` · `20` · `24` 중에서 골라요.
- **선과 채움**: `variant`로 선(`line`)과 채움(`fill`)을 바꿔요.
- **색**: 아이콘은 글자 색을 따라가요. `text-icon-*` 클래스로 정해요.
- **이름 붙이기**: 아이콘만으로 뜻을 전하는 곳에는 `aria-label`을 줘요.
- **버튼 안**: 버튼에 넣은 아이콘은 버튼 크기에 맞춰져요.

## Props

나머지 `<svg>` 속성도 그대로 받아요.\
훅을 쓰지 않아서 서버 컴포넌트에서 바로 쓸 수 있어요.

| 이름         | 타입               | 기본값   | 설명                                      |
| ------------ | ------------------ | -------- | ----------------------------------------- |
| `size`       | `16 \| 20 \| 24`   | `24`     | 크기(px)                                  |
| `variant`    | `"line" \| "fill"` | `"line"` | 선 또는 채움                              |
| `aria-label` | `string`           | -        | 아이콘만으로 뜻을 전할 때 읽힐 이름       |
| `className`  | `string`           | -        | 추가 클래스. 색은 글자 색 클래스로 정해요 |

## Guidelines

컴포넌트 이름은 Figma의 아이콘 이름을 PascalCase로 바꾸고 `Icon`을 붙여요.

| Figma 이름         | 컴포넌트              |
| ------------------ | --------------------- |
| `arrow-left`       | `ArrowLeftIcon`       |
| `magnifying-glass` | `MagnifyingGlassIcon` |
| `x`                | `XIcon`               |

- 아이콘은 기본적으로 장식용이라 스크린리더가 읽지 않아요. 글자 없이 아이콘만 있으면 `aria-label`을 줘요.
- 색은 `text-icon-*` 클래스로만 정해요. hex 값을 쓰지 않아요.
- 누르는 아이콘은 아이콘 대신 [`IconButton`](/components/icon-button)을 써요.
- 아이콘 도형은 [Phosphor Icons](https://phosphoricons.com)(MIT)예요.
