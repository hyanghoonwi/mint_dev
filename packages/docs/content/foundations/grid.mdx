# Spacing · Grid

간격 12단계와 반응형 그리드로 화면의 비율과 정렬을 맞춰요. 모바일웹과 PC를 하나의 그리드로 다뤄요.

## Grid

브라우저 창 폭을 바꿔 보세요. 컬럼이 4 → 8 → 12개로 바뀌어요.

<GridColumns />

구간마다 바뀌는 것은 컬럼 수뿐이에요. 거터와 좌우 여백은 모든 구간에서 20px이에요.

| 구간     | 화면 폭       | 컬럼 | 거터 | 좌우 여백 |
| -------- | ------------- | ---- | ---- | --------- |
| 모바일   | 0 \~ 767px    | 4    | 20   | 20        |
| 태블릿   | 768 \~ 1023px | 8    | 20   | 20        |
| 데스크톱 | 1024px \~     | 12   | 20   | 20        |

## Spacing

4px 단위의 12단계예요. 이름은 Figma의 `spacing-N`과 같고, 클래스의 숫자는 px ÷ 4예요.

<SpacingScale />

## Usage

화면은 `Container`와 `Grid`로 짜요. 칸마다 구간별로 몇 컬럼을 차지할지만 정하면 돼요. 자세한 사용법은 컴포넌트 페이지에 있어요.

<PageLink
  to="/components/container-grid"
  title="Container · Grid"
  description="구간별 칸 수(span), 중첩, 예시와 Props를 볼 수 있어요."
/>

기본 모양은 이렇게 써요.

```tsx
import { Container, Grid } from "@futurewiz-rms/mint";

<Container>
  <Grid>
    <Grid.Item span={{ base: 4, tablet: 4, desktop: 3 }}>…</Grid.Item>
  </Grid>
</Container>;
```

간격은 클래스로 써요. `p-`(안쪽 여백), `m-`(바깥 여백), `gap-`(간격)과 방향(`px-`, `mt-` 등)에 모두 같은 숫자를 써요.

```tsx
<section className="mt-10 p-5">…</section>
```

## Guidelines

- 콘텐츠는 최대 1440px이에요. 더 넓은 화면에서는 콘텐츠를 가운데에 두고 바깥 여백만 늘어나요.
- 1024 \~ 1439px에서는 컬럼 12개, 거터·여백 20px은 그대로이고 컬럼 폭만 줄어요.
- 모바일과 태블릿은 화면을 가득 채워요. 폰을 가로로 눕힌 화면(약 800 \~ 900px)은 태블릿이에요.
- 간격은 12단계 안의 값만 써요. 단계 밖의 값(`p-7`, `p-[13px]`)은 쓰지 않아요.
- 배치는 `Container`·`Grid`로 하고, `div`에 그리드 클래스를 직접 쓰지 않아요.
