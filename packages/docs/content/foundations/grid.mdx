# 간격 · 그리드

모바일 웹과 PC 웹을 하나로 다루는 반응형 그리드와 4px 단위 간격입니다. 화면 폭 구간마다 컬럼 수가 바뀌고, 글자 크기는 구간과 관계없이 고정입니다.

## 그리드

브라우저 창 폭을 바꿔 보세요. 컬럼이 4 → 8 → 12개로 바뀝니다.

<GridColumns />

| 구간    | 화면 폭      | 컬럼 | 거터 | 좌우 여백 |
| ------- | ------------ | ---- | ---- | --------- |
| Mobile  | 0 ~ 767px    | 4    | 20   | 20        |
| Tablet  | 768 ~ 1023px | 8    | 20   | 20        |
| Desktop | 1024px ~     | 12   | 20   | 20        |

화면은 `Container`와 `Grid`로 짭니다. 칸마다 구간별로 몇 컬럼을 차지할지만 정하면 됩니다. 자세한 사용법은 [Container · Grid](/components/container-grid)에 있습니다.

```tsx
import { Container, Grid } from "@futurewiz-rms/mint";

<Container>
  <Grid>
    <Grid.Item span={{ base: 4, tablet: 4, desktop: 3 }}>…</Grid.Item>
  </Grid>
</Container>;
```

## PC 규칙

- 콘텐츠는 최대 1440px입니다. 더 넓은 화면에서는 콘텐츠를 가운데에 두고 바깥 여백만 늘어납니다.
- 1024 ~ 1439px에서는 컬럼 12개, 거터 20, 여백 20은 그대로이고 컬럼 폭만 줄어듭니다.
- 모바일과 태블릿은 화면을 가득 채웁니다. 폰을 가로로 눕힌 화면(약 800~900px)은 태블릿입니다.

## 간격

4px 단위의 12단계입니다. 이름은 Figma의 `spacing-N`과 같고, 클래스의 숫자는 px ÷ 4입니다.

<SpacingScale />

```tsx
<section className="mt-10 p-5">…</section>
```

`p-`(안쪽 여백), `m-`(바깥 여백), `gap-`(간격)과 방향(`px-`, `mt-` 등)을 모두 같은 숫자로 씁니다. 12단계 밖의 값(`p-7`, `p-[13px]`)은 쓰지 않습니다.
