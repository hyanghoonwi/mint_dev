# useFileUpload

고른 파일 목록과 업로드 상태(미리보기·진행률·취소·다시 시도·용량 검사)를 관리하는 훅이에요.

<ComponentBadges />

## Usage

돌려받은 `uploaderProps`를 [File uploader](/components/file-uploader)에, `itemProps(item)`을 `FileItem`에 펼쳐요. 클라이언트 컴포넌트에서 써요.

```tsx
const upload = useFileUpload({
  maxSize: 10 * 1024 * 1024,
  maxFiles: 5,
  upload: (file, { onProgress, signal }) =>
    axios.post("/api/files", toForm(file), {
      onUploadProgress: (event) =>
        onProgress((event.loaded / (event.total ?? 1)) * 100),
      signal,
    }),
});

<FileUploader
  label="증빙 서류"
  description="PDF · 최대 10MB"
  multiple
  {...upload.uploaderProps}
/>;
{
  upload.items.map((item) => (
    <FileItem key={item.id} {...upload.itemProps(item)} />
  ));
}
```

`upload`를 주면 고르자마자 올리고, 주지 않으면 목록만 관리해요. 평소 도움말(`helper`)·상태(`status`)는 `uploaderProps`보다 앞에 적어요. 개수 초과·형식 오류가 있을 때만 `status="negative"`와 오류 문구로 바뀌어요.

- **자동 업로드**: 직접 파일을 골라 보세요. 이미지는 썸네일이 보이고, 진행률이 차오르다 완료돼요. 올리는 중에 ×를 누르면 `signal`로 업로드가 멈춰요. 10MB보다 큰 파일은 실패로 남아요.
- **실패와 다시 시도**: `upload`가 실패하면 이유와 "다시 시도"가 보여요. 이 예시는 처음 한 번은 실패해요.
- **폼으로 보내기**: `upload` 없이 목록만 관리하고, 보낼 때 `items`의 `file`을 `FormData`에 담아요.

## API

`useFileUpload(options)`가 돌려주는 값이에요.

| 이름            | 타입                      | 설명                                                                                |
| --------------- | ------------------------- | ----------------------------------------------------------------------------------- |
| `items`         | `FileUploadItem[]`        | 목록의 파일들(`id`·`file`·`name`·`sizeLabel`·`preview`·`status`·`progress`·`error`) |
| `uploading`     | `boolean`                 | 올리는 중인 파일이 있는지. 제출 버튼을 막을 때 써요                                 |
| `error`         | `string \| null`          | 목록 전체 오류(개수 초과·형식)                                                      |
| `uploaderProps` | `object`                  | `FileUploader`에 펼치는 값                                                          |
| `itemProps`     | `(item) => object`        | `FileItem`에 펼치는 값(지우기·다시 시도 포함)                                       |
| `add`           | `(files: File[]) => void` | 파일을 직접 더해요                                                                  |
| `remove`        | `(id: string) => void`    | 파일을 지워요. 올리는 중이면 취소해요                                               |
| `retry`         | `(id: string) => void`    | 실패한 파일을 다시 올려요                                                           |
| `clear`         | `() => void`              | 목록을 비워요                                                                       |

`options`로 넘기는 값이에요.

| 이름       | 타입                                        | 기본값 | 설명                                                            |
| ---------- | ------------------------------------------- | ------ | --------------------------------------------------------------- |
| `maxSize`  | `number`                                    | -      | 파일 하나의 최대 용량(byte). 넘으면 실패로 남기고 이유를 붙여요 |
| `maxFiles` | `number`                                    | -      | 최대 개수. 넘는 파일은 받지 않고 오류를 알려요                  |
| `upload`   | `(file, { onProgress, signal }) => Promise` | -      | 파일을 올리는 함수. 주면 고르자마자 올려요                      |
| `messages` | `{ tooLarge, tooMany, rejected, failed }`   | -      | 안내 문구를 바꿔요                                              |

## Guidelines

- 목록·미리보기·진행률·취소를 화면마다 직접 만들지 않고 이 훅을 써요.
- `upload`에는 진행률(`onProgress`)과 중단 신호(`signal`)를 꼭 연결해요. 진행률을 알 수 없는 업로드는 끝날 때까지 "올리는 중"으로 보여요.
- 용량 초과는 다시 올려도 같아서 "다시 시도"를 보이지 않아요. 이유만 알려요.
- 이미지 미리보기 주소는 훅이 만들고 돌려줘요. `item.preview`를 직접 돌려주지 않아요.
