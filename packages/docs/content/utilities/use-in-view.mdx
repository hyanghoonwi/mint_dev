# useInView

요소가 화면(또는 스크롤 상자)에 들어왔는지 알려 주는 훅이에요.

<ComponentBadges />

## Usage

`ref`를 관찰할 요소에 붙이면 `inView`가 보일 때 `true`, 안 보일 때 `false`가 돼요. 클라이언트 컴포넌트에서 써요.

```tsx
const { ref, inView } = useInView();

<div ref={ref}>{inView ? "보여요" : "안 보여요"}</div>;
```

스크롤 상자 안에서 볼 때는 그 상자를 `root`로 넘겨요. 넘기지 않으면 브라우저 화면이 기준이에요.

```tsx
const [root, setRoot] = useState<HTMLDivElement | null>(null);
const { ref, inView } = useInView({ root });
```

## API

`useInView(options)`가 돌려주는 값이에요.\
`[ref, inView, entry]` 배열로도, `{ ref, inView, entry }` 객체로도 꺼낼 수 있어요.

| 이름     | 타입                                     | 설명                                               |
| -------- | ---------------------------------------- | -------------------------------------------------- |
| `ref`    | `(node: Element \| null) => void`        | 관찰할 요소에 붙여요                               |
| `inView` | `boolean`                                | 지금 보이는지. 서버 렌더에서는 `initialInView`예요 |
| `entry`  | `IntersectionObserverEntry \| undefined` | 마지막 관찰 결과(보이는 비율 등)                   |

`options`로 넘기는 값이에요.

| 이름             | 타입                          | 기본값  | 설명                                                                 |
| ---------------- | ----------------------------- | ------- | -------------------------------------------------------------------- |
| `threshold`      | `number \| number[]`          | `0`     | 얼마나 보여야 보인 것으로 칠지(0\~1). `0`이면 1px만 보여도 돼요      |
| `root`           | `Element \| Document \| null` | -       | 기준이 되는 스크롤 상자. 없으면 브라우저 화면이에요                  |
| `rootMargin`     | `string`                      | -       | 기준 영역을 넓히거나 줄이는 여백. `"0px 0px 200px 0px"`면 200px 미리 |
| `triggerOnce`    | `boolean`                     | `false` | 처음 보일 때 한 번만 알리고 관찰을 멈춰요                            |
| `skip`           | `boolean`                     | `false` | 관찰하지 않아요                                                      |
| `initialInView`  | `boolean`                     | `false` | 첫 관찰 결과가 나오기 전의 값                                        |
| `fallbackInView` | `boolean`                     | -       | 관찰 기능이 없는 브라우저에서 쓸 값                                  |
| `onChange`       | `(inView, entry) => void`     | -       | 보이는 상태가 바뀔 때마다 불려요                                     |

## Guidelines

- 무한 스크롤은 `onChange`보다 `inView`와 `useEffect`로 불러와요. 불러온 뒤에도 끝이 계속 보이면 한 번 더 불러와요.
- 바닥에 닿기 전에 미리 불러오려면 `rootMargin`을 줘요.
- 서버 렌더와 첫 화면에서는 `inView`가 `false`예요. 검색이나 스크린리더가 읽어야 하는 중요한 내용을 `inView`로 숨기지 않아요.
- 보일 때 나타나는 효과는 `triggerOnce`로 한 번만 보여 줘요. 스크롤할 때마다 깜빡이지 않게 해요.
