# Grid

모바일 웹과 PC 웹을 하나의 시스템으로 다루는 반응형 그리드의 규격입니다. 화면 폭 구간마다 컬럼 수, 거터, 여백이 바뀌고 **글자 크기는 구간과 관계없이 고정**입니다. Figma의 `Grid` 가이드와 `Breakpoints` 도식과 같은 값입니다.

화면에 쓰는 방법은 [Container · Grid](../components/common/grid) 컴포넌트를 보세요. 이 페이지는 그 컴포넌트가 따르는 규격입니다.

## 기본 원칙

| 원칙        | 내용                                                                                                            |
| ----------- | --------------------------------------------------------------------------------------------------------------- |
| 구간        | 모바일, 태블릿, PC 3단계입니다. 컬럼은 4, 8, 12개로 늘어나고, 한 줄에 놓이는 카드 수가 화면 폭에 맞게 바뀝니다. |
| 글자 크기   | 구간과 관계없이 고정입니다. 반응형은 레이아웃(그리드, 여백, 컬럼 수)에서만 처리합니다.                          |
| 모바일 우선 | 모바일이 기본이고 `min-width` 미디어쿼리로 구간을 올려 갑니다.                                                  |

## 구간별 설정

| 구간    | 화면 폭 (CSS) | 디자인 프레임 | 컬럼 | 거터 | 좌우 여백 | 컬럼 폭 |
| ------- | ------------- | ------------- | ---- | ---- | --------- | ------- |
| Mobile  | 0 ~ 767px     | 360px         | 4    | 20   | 20        | 65      |
| Tablet  | 768 ~ 1023px  | 768px         | 8    | 20   | 20        | 73.5    |
| Desktop | 1024px ~      | 1440px        | 12   | 20   | 20        | 98.33   |

컬럼 폭은 `(프레임 폭 - 좌우 여백 2개 - 거터 × (컬럼 수 - 1)) ÷ 컬럼 수`이고 소수점이 될 수 있습니다. 가장 작은 화면은 320px까지 고려하며, 이때 4컬럼의 컬럼 폭은 55px입니다.

## 브레이크포인트

| 구간           | 시작 폭 | 이름      |
| -------------- | ------- | --------- |
| (모바일, 기본) | 0       | -         |
| 태블릿         | 768px   | `tablet`  |
| 데스크톱       | 1024px  | `desktop` |

- 폰을 가로로 눕힌 화면(약 800~900px)은 태블릿 구간(8컬럼)에 들어갑니다. 의도한 동작입니다.
- 컴포넌트가 이 구간을 알아서 처리하므로, 보통은 이름을 직접 쓸 일이 없습니다. Tailwind로 직접 레이아웃을 짤 때만 `tablet:`, `desktop:` 접두어를 씁니다(Tailwind 기본 `sm:` `md:` `lg:`는 없습니다).

## PC 규칙

- **콘텐츠 최대 폭은 1440px**입니다(안쪽 여백 포함). 이보다 넓은 화면에서는 콘텐츠를 가운데에 고정하고 **좌우 바깥 여백만 늘어납니다.** 바깥 여백은 `(화면 폭 - 1440) ÷ 2`입니다. 모바일과 태블릿은 제한 없이 화면을 가득 채웁니다.
- **1024 ~ 1439px**에서는 컬럼 12개, 거터 20, 여백 20은 그대로이고 컬럼 폭만 줄어듭니다.
- **여백과 거터는 모든 구간에서 20**으로 통일합니다. 20은 간격 스케일의 `spacing-20` 값입니다.

## CSS 변수

컴포넌트로 만들 수 없는 레이아웃(서드파티 위젯의 틀 등)을 직접 짤 때 읽는 값입니다.

| 변수                  | 값                | 설명                                                             |
| --------------------- | ----------------- | ---------------------------------------------------------------- |
| `--mint-grid-columns` | `4` → `8` → `12`  | 컬럼 수. 768px, 1024px에서 바뀝니다                              |
| `--mint-grid-gutter`  | `20px`            | 컬럼 사이 간격                                                   |
| `--mint-grid-margin`  | `20px`            | 화면 좌우 여백                                                   |
| `--mint-content-max`  | `none` → `1440px` | 콘텐츠 최대 폭. `none`은 제한 없음(화면 가득). 1024px부터 1440px |

## 간격 스케일

4px 단위의 12단계입니다. Figma의 `spacing-N`과 이름·값이 같고, 이 밖의 값은 쓰지 않습니다.

<Example name="grid/Spacing" hideCode />

| 쓰는 곳              | 방법                                                                                                         |
| -------------------- | ------------------------------------------------------------------------------------------------------------ |
| CSS                  | `padding: var(--mint-spacing-20)`                                                                            |
| 클래스 (`style.css`) | `p-5` `px-5` `m-5` `gap-5` … 번호는 px ÷ 4입니다 (`spacing-20` = `p-5`). `p-` `m-` `gap-` 계열 모두 같습니다 |

```tsx
<div className="p-5 gap-3">…</div>
```
