# Container · Grid

반응형 페이지 레이아웃을 위한 두 컴포넌트입니다. 상태가 없어서 서버 컴포넌트에서 그대로 쓸 수 있습니다. 컬럼 수(모바일 4 · 태블릿 8 · 데스크톱 12), 거터와 여백(20px), 콘텐츠 최대 폭(1440px)은 [Grid 규격](../../foundations/grid)에 따라 알아서 바뀝니다.

- `Container`: 페이지 틀. 화면 좌우 여백을 두고 콘텐츠를 가운데에 고정합니다.
- `Grid`: 컬럼 그리드. 안에 `Grid.Item`을 놓고, 칸마다 구간별로 몇 컬럼을 차지할지 정합니다.

## Usage

`Grid.Item`의 `span`에 구간별 컬럼 수를 넣습니다. 아래는 카드가 모바일에서 한 줄에 1개, 태블릿에서 2개, 데스크톱에서 4개 놓이는 예시입니다. 브라우저 창 폭을 바꿔 보세요.

<Example name="grid/Cards" />

각 구간의 컬럼 수는 모바일 4, 태블릿 8, 데스크톱 12입니다. `span`을 생략하면 한 줄을 모두 차지합니다. `tablet`을 생략하면 `base` 값을, `desktop`을 생략하면 `tablet`(없으면 `base`) 값을 따릅니다.

| 한 줄에 놓을 카드 수 | `span`                                |
| -------------------- | ------------------------------------- |
| 1개 / 1개 / 1개      | `{ base: 4, tablet: 8, desktop: 12 }` |
| 1개 / 2개 / 4개      | `{ base: 4, tablet: 4, desktop: 3 }`  |
| 2개 / 4개 / 6개      | `{ base: 2, tablet: 2, desktop: 2 }`  |

## Props

### Container

| Prop        | 타입                  | 기본값 | 설명                |
| ----------- | --------------------- | ------ | ------------------- |
| `className` | `string`              | -      | 추가 클래스         |
| `ref`       | `Ref<HTMLDivElement>` | -      | React 19 `ref` prop |

나머지 `<div>` 속성은 그대로 전달됩니다.

### Grid

`<div>` 속성을 그대로 받습니다. 컬럼 수와 거터는 구간에 따라 자동으로 정해지므로 prop이 없습니다.

### Grid.Item

| Prop        | 타입                                          | 기본값                                        | 설명                                                             |
| ----------- | --------------------------------------------- | --------------------------------------------- | ---------------------------------------------------------------- |
| `span`      | `{ base: 1~4; tablet?: 1~8; desktop?: 1~12 }` | `{ base: 4, tablet: 8, desktop: 12 }` (한 줄) | 구간별로 차지할 컬럼 수. 구간마다 넣을 수 있는 최댓값이 다릅니다 |
| `className` | `string`                                      | -                                             | 추가 클래스                                                      |

나머지 `<div>` 속성은 그대로 전달됩니다.
