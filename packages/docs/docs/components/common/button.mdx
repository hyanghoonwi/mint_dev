# Button

텍스트가 있는 기본 버튼입니다. 사용자의 동작을 받는 곳에 사용합니다. 상태가 없어서 서버 컴포넌트에서도 그대로 쓸 수 있고, `onClick`을 넘길 때만 클라이언트 컴포넌트 안에서 씁니다.

## Sizes

`size`로 높이를 조절합니다. 높이는 `sm` 32px · `md` 40px · `lg` 48px · `xl` 56px이며 기본값은 `md`입니다. 터치 화면에서 누르는 버튼은 `md` 이상을 씁니다.

## Props

| Prop         | 타입                                        | 기본값      | 설명                                               |
| ------------ | ------------------------------------------- | ----------- | -------------------------------------------------- |
| `variant`    | `"primary" \| "tint" \| "line" \| "danger"` | `"primary"` | 시각 스타일                                        |
| `size`       | `"sm" \| "md" \| "lg" \| "xl"`              | `"md"`      | 높이 32/40/48/56px                                 |
| `fullWidth`  | `boolean`                                   | `false`     | 부모 폭을 꽉 채움                                  |
| `leftAddon`  | `ReactNode`                                 | -           | 텍스트 앞(왼쪽)에 붙는 요소                        |
| `rightAddon` | `ReactNode`                                 | -           | 텍스트 뒤(오른쪽)에 붙는 요소                      |
| `type`       | `"button" \| "submit" \| "reset"`           | `"button"`  | 폼 안에서 실수로 제출되지 않도록 기본값이 `button` |
| `ref`        | `Ref<HTMLButtonElement>`                    | -           | React 19 `ref` prop                                |
