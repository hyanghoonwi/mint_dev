크립토랩의 모든 화면을
같은 언어로

MINT는 한국경제TV 크립토랩의 디자인 시스템입니다. 시세와 차트, 커뮤니티를 만드는 데 필요한 파운데이션, 컴포넌트, 패턴을 한곳에서 확인하세요.

원칙

숫자가 먼저 읽힌다가격과 변동률은 고정폭 숫자로, 화면에서 가장 높은 대비로 표시합니다.
색만으로 구분하지 않는다상승·하락은 빨강·파랑과 함께 ▲▼ 기호와 부호를 항상 같이 씁니다.
다크와 라이트는 동등하다모든 토큰은 두 테마의 값을 함께 정의하고, 컴포넌트는 토큰만 참조합니다.
시작하기

시작하기

MINT는 React 컴포넌트 패키지와 디자인 토큰으로 제공됩니다. 세 단계로 프로젝트에 적용할 수 있습니다.

1. 설치

$ npm install @cryptolab/mint

2. Provider 설정

앱 최상단을 MintProvider로 감싸고 테마를 지정합니다. theme 값은 dark, light, system 중 하나입니다.

import { MintProvider } from '@cryptolab/mint';
import '@cryptolab/mint/styles.css';

export default function App() {
  return (
    <MintProvider theme="system">
      <Routes />
    </MintProvider>
  );
}

3. 첫 컴포넌트

import { Button, PriceChange } from '@cryptolab/mint';
