# 표시

> 색인: [`../AGENTS.md`](../AGENTS.md)

- **`Avatar`** — 사용자·대상을 나타내는 프로필 칸. 서버 컴포넌트에서도 쓸 수 있습니다(`onClick`을 넘길 때만 클라이언트 컴포넌트 안에서 씁니다).
  - `size`: `16` · `24` · `32` · `40`(기본) · `48` · `64`(px). `16`은 글자 옆 작은 표시용(누르는 용도·숫자 배지 금지, 자동 배지는 8px 점). 구간별 객체도 받음(`{ base: 32, tablet: 48 }`, 배지 위치·자동 배지 크기도 따라감)
  - `variant`: `person`(기본, 원형) · `brand`(둥근 사각형, 서비스·코인·조직 등 사람이 아닌 대상)
  - `src` → 이미지, 없으면 `name`의 첫 글자, 둘 다 없으면 `icon`(기본은 사용자 아이콘). 이미지가 오기 전·실패하면 회색 바탕만 보입니다(자리표시 아이콘 없음)
  - `name`: 스크린리더에 읽힐 이름이기도 합니다. 이미지·아이콘만 쓸 때도 `name`이나 `aria-label`을 붙입니다
  - `badge`: `"dot"` 또는 숫자(99 초과는 `99+`, 0 이하는 숨김). `badgeSize`(`xs`~`xl`)로 배지 크기를 따로 고를 수 있고, 생략하면 아바타 크기에 맞춥니다(24 `xs` · 32 `sm` · 40 `md` · 48 `lg` · 64 `xl`). 위치는 아바타 크기를 따릅니다
  - `disabled`, `onClick`(주면 눌리는 `<button>`이 됨, hover·pressed 같은 색)
- **`AvatarGroup`** — 아바타를 흰 테두리로 겹쳐 놓는 묶음. 서버 컴포넌트에서도 쓸 수 있습니다.
  - `items`(필수): `{ src?, name?, icon? }[]`
  - `size`(기본 40, 구간별 객체도 받음 — 겹침·`+N` 칸도 따라감), `max`(기본 3, 넘치면 `+N`), `count`(넘친 칸 글자를 직접 정함)
  - `aria-label`로 몇 명인지 알려 줍니다
- **`Badge`** — 상태·종류를 짧게 알리는 표시 전용 라벨(눌러도 동작 없음, 선택은 Chip). 서버 컴포넌트에서도 쓸 수 있습니다. 문구는 `children`으로 넣습니다.
  - `variant`: `fill`(기본, 진한 배경, 화면당 한두 개) · `weak`(연한 배경, 목록·카드 안에 여러 개)
  - `color`: `brand`(기본, 강조) · `neutral`(일반) · `danger`(오류·임박) · `success`(완료) · `warning`(주의) · `teal` `violet` `pink`(의미 없는 분류용, 예: 카테고리 구분). 의미대로 고르고, 상태를 알릴 때는 앞의 5색을 씁니다
  - `size`: `sm` 20 · `md` 22(기본) · `lg` 28px. 같은 화면에서는 하나로 맞춥니다. 구간별 객체도 받음(`{ base: "sm", tablet: "md" }`)
  - 문구는 1~4자로 짧게. 색만으로 뜻을 전하지 않고, 화살표·아이콘을 붙이지 않습니다
- **`PriceChange`** — 가격·시세가 오르내린 정도를 보여 주는 표시 전용 부품(Figma `Price Change`). 서버 컴포넌트에서도 쓸 수 있습니다. 상세 규칙은 `components/price-change/AGENTS.md`
  - `direction`(필수): `up`(상승, 빨강) · `down`(하락, 파랑) · `flat`(보합, 회색)
  - `type`: `amount`(기본, 화살표 ▲ ▼, 보합은 가로선) · `percent`(부호 +, -). 한 표시에 화살표와 부호를 함께 쓰지 않습니다
  - `children`: 숫자만 넣습니다(`"1,200"`, `"3.42%"`). 부호·화살표를 직접 넣지 않습니다. 소수점 자릿수는 맞춰서 넘깁니다(`0.00%`)
  - `variant`: `text`(기본, 글자만) · `weak`(연한 배경)
  - `size`: `sm`(12px, 표·목록) · `md`(14px, 기본) · `lg`(16px, 요약 카드). 구간별 객체도 받음(`{ base: "sm", desktop: "md" }`). 같은 목록에서는 하나로 맞춥니다
  - 스크린리더에는 "상승·하락·보합"이 함께 읽힙니다. 상태·분류 라벨은 `Badge`를 씁니다
- **`Thumbnail`** — 콘텐츠 이미지(뉴스·카드·상품)를 정해진 비율로 보여 주는 틀(Figma `Thumbnail`). 서버 컴포넌트에서도 쓸 수 있습니다. 사람·대상(프로필·거래소)은 `Avatar`를 씁니다. 상세 규칙은 `components/thumbnail/AGENTS.md`
  - `aspectRatio`: 가로형 `1:1`(기본) `5:4` `4:3` `3:2` `16:10` `1.618:1` `16:9` `2:1` `21:9`, 세로형 `4:5` `3:4` `2:3` `10:16` `1:1.618` `9:16` `1:2` `9:21`. 가로는 `16:9`, 정사각형은 `1:1`을 기본으로. 구간별 객체도 받음(`{ base: "1:1", tablet: "16:9" }`)
  - 폭은 부모(또는 `style`·`className`의 폭)를 따르고 높이가 비율로 정해집니다
  - `src`·`alt`(꾸밈용이면 `""`), `loading`(기본 `lazy`, 첫 화면 위쪽은 `eager`), `fit`(`cover` 기본 · `contain`)
  - `image`: Next.js `<Image fill />`처럼 직접 만든 이미지 요소를 넘길 때(`src` 대신). core는 `next/image`를 쓰지 않습니다
  - `radius`(모서리 8, 카드 위에서 켬) · `border`(1px `border-default`, 흰 배경에 흰 이미지일 때) · `overlay`(이미지 위 막, 글자를 올릴 때) · `overlayColor`(막 색, 기본은 옅은 `fill-pressed`)
  - `children`: 이미지 위에 올릴 내용(제목 등). 이미지가 없으면 회색 바탕에 이미지 아이콘이 보입니다
  - 한 목록에서는 비율·모서리를 맞추고, 불러오기 전에는 같은 비율의 `SkeletonRectangle`(`height="auto"` + `style={{ aspectRatio: "16 / 9" }}`)을 보여 줍니다
- **`Snackbar`** — 작업 뒤 다음 행동(버튼 1개)을 제안하는 메시지(Figma `Snackbar`). 이 컴포넌트는 **본문 안에 그대로 렌더링**해 두는 용도이고, 행동 뒤에 잠시 띄우려면 `useSnackbar`([오버레이](overlay.md))를 씁니다. 서버 컴포넌트에서도 쓸 수 있습니다(`onClose`나 `addOn`의 버튼에 `onClick`을 넘길 때만 클라이언트 컴포넌트 안에서). 상세 규칙은 `components/snackbar/AGENTS.md`
  - `heading`(필수, 한 줄·말줄임) · `description`(필요할 때만) · `variant`(`normal` 기본 · `positive` · `cautionary` · `negative`) · `icon`(종류별 아이콘, 기본 끔)
  - `addOn`: 오른쪽에 붙일 `ReactNode`. 다음 행동 버튼 하나를 직접 넣습니다(`<Button variant="outline" color="neutral" size="md">되돌리기</Button>`, 레이블 2~4자). `onClose`: 넘기면 닫기 버튼(X). 숨기는 것은 사용하는 쪽이 상태로 합니다
  - 폭은 놓인 자리를 채우고 최대 420. 본문에 붙어 있어 그림자가 없습니다(`useSnackbar`로 띄우면 `shadow-floating`)
  - 버튼은 하나만. 되돌릴 수 없는 일의 확인은 Alert, 결과만 알리고 사라질 때는 `useToast`
- **`Text`** — 토큰 텍스트 스타일로 글자를 그리는 컴포넌트(Figma Typography 59개 스타일만). 서버 컴포넌트에서도 쓸 수 있습니다.
  - `variant`(필수): `title-1-bold`, `body-2-regular`처럼 역할-번호-웨이트. 구간별 객체도 받음(`{ base: "title-3-bold", desktop: "title-1-bold" }`, 같은 크기 표 안에서 고름. 큰 제목에만)
  - `as`: 태그(`span` 기본, `p`·`h1`~`h6`·`label` 등). 모양과 따로 고릅니다
  - `color`: `primary`(기본) · `strong` · `secondary` · `tertiary` · `subtle` · `disabled` · `brand` · `danger` · `success` · `warning` · `on-fill` · `inherit`(감싼 요소의 색을 따름, 버튼·배지 안처럼 필요할 때만). 색·크기를 `className`으로 바꾸지 않습니다
  - `lines`: 1~4줄 넘으면 말줄임. 클래스(`text-body-2-regular`)를 직접 써도 됩니다. 상세 규칙은 `components/text/AGENTS.md`
