# Category 사용 규칙

`Category`를 쓰거나 고칠 때 **이 문서대로 쓰는 것을 권장**합니다. 출처는 Figma `Category`(node `2200:6278`)와 `Category Guidelines`(node `2200:6493`)입니다. Figma와 이 문서가 다르면 Figma가 맞습니다.

- **같은 목록을 거르거나 분류를 고르는 칩 목록**입니다. 한 번에 하나만 선택하고, 칩이 많으면 가로로 스크롤합니다.
- 클라이언트 컴포넌트(`"use client"`)입니다. 선택 상태, 키보드 이동, 스크롤 위치에 따른 그라데이션을 다룹니다. 서버 컴포넌트에서 import해도 되지만 `onChange`는 클라이언트 컴포넌트에서 넘깁니다.
- 반응형 웹(모바일웹 ~ PC)에서 같은 컴포넌트를 씁니다. 폭은 부모를 따르고, 넘치면 스크롤합니다.

## 언제 쓰나요

화면 내용 자체가 바뀌면 Tab을, 목록을 거르면 Category를 써요.

|      | Category                           | Tab                             |
| ---- | ---------------------------------- | ------------------------------- |
| 목적 | 같은 목록을 거르거나 분류를 골라요 | 같은 화면의 내용(섹션)을 바꿔요 |
| 모양 | 알약형 칩                          | 밑줄형                          |
| 개수 | 3~7개, 넘치면 가로 스크롤          | 5개 이하는 Fill, 6개 이상은 Hug |
| 선택 | 한 번에 하나만 선택해요            | 항상 하나가 선택돼요            |

Tab은 MINT에 아직 없습니다.

## 구성

종류, 크기, 모양과 가장자리 그라데이션을 골라요.

| 구성                        | 선택지                                 | 쓰는 곳                                                                                          |
| --------------------------- | -------------------------------------- | ------------------------------------------------------------------------------------------------ |
| 종류(`variant`)             | `solid` · `outline`                    | 흰 화면에서는 Solid, 회색 배경 위에서는 Outline                                                  |
| 크기(`size`)                | `lg`(Large 40, 기본) · `md`(Medium 32) | Large는 모바일웹 기본, Medium은 촘촘한 영역. 구간별 값도 받아요(`{ base: "lg", desktop: "md" }`) |
| 모양(`shape`)               | `square` · `pill`                      | 둥근 사각형 · 알약형                                                                             |
| 전체(`all`)                 | 켜면 맨 앞에 "전체"가 생겨요           | 목록 전체를 보는 기본 선택지로 써요                                                              |
| 가장자리 그라데이션(`fade`) | 왼쪽(Leading) · 오른쪽(Trailing)       | 칩이 화면 폭을 넘을 때만 나타나요                                                                |

- **선택 색**: `solid`는 회색 칩(글자 회색) → 선택하면 검정 칩(흰 글자). `outline`은 연회색 테두리(글자 회색) → 선택하면 진한 테두리(진한 글자).
- **그라데이션은 자동**입니다. Figma의 `leading fade`·`trailing fade`를 직접 켜지 않고, 스크롤할 칩이 남은 쪽에만 나타납니다. `fade={false}`로 끌 수 있습니다.
- **"전체"** 칩의 값은 `"all"`(`CATEGORY_ALL`)입니다. 기본으로 켜져 있고 처음 선택 값입니다. 글자는 `allLabel`로 바꿉니다.
- 칩마다 `icon`(글자 앞 아이콘, Figma customize `leading icon`)과 `badge`(글자 오른쪽 위 빨간 점)를 줄 수 있습니다.

```tsx
const [category, setCategory] = useState("all");

<Category
  aria-label="코인 분류"
  value={category}
  onChange={setCategory}
  items={[
    { value: "major", label: "메이저" },
    { value: "defi", label: "디파이", badge: true },
    { value: "meme", label: "밈" },
  ]}
/>;
```

## 사용 규칙

스크롤된다는 사실을 알려 주세요.

| 구분 | 내용                                                                     |
| ---- | ------------------------------------------------------------------------ |
| 권장 | 칩이 화면 폭을 넘으면 오른쪽 그라데이션을 켜서 더 있다는 걸 알려요(자동) |
| 권장 | 맨 앞에 "전체"를 두고 기본 선택으로 해요                                 |
| 금지 | 칩을 두 줄로 줄바꿈하지 않아요. 한 줄로 두고 스크롤해요                  |
| 금지 | 여러 개를 동시에 선택하게 하지 않아요. 복수 선택은 Checkbox를 써요       |

- 칩은 3~7개를 권장합니다. 글자는 짧은 명사로 씁니다.
- `className`으로 칩을 여러 줄로 감싸지 않습니다(`flex-wrap` 금지).
- 화면 내용(섹션)을 통째로 바꾸는 곳에는 쓰지 않습니다. Tab을 씁니다.

## 접근성

누구나 쓸 수 있도록 다음을 지켜 주세요.

- **그라데이션은 보조 표시예요.** 그라데이션이 없어도 스크롤된다는 걸 알 수 있게 칩이 가장자리에서 잘려 보이게 둡니다(양옆 여백 16 안에서 칩이 잘림).
- **선택 상태를 색만으로 알리지 않아요.** 선택된 칩은 배경(테두리)과 글자 색 대비를 함께 바꿉니다.
- 묶음은 `radiogroup`, 칩은 `radio`(`aria-checked`)로 읽힙니다. **`aria-label`(예: "코인 분류")을 꼭 줍니다.**
- 키보드: <kbd>Tab</kbd>으로 선택된 칩에 들어오고, <kbd>←</kbd>·<kbd>→</kbd>로 옆 칩을 선택하고, <kbd>Home</kbd>·<kbd>End</kbd>로 처음·끝 칩을 선택합니다. 선택된 칩이 화면 밖에 있으면 보이게 스크롤됩니다.
- `badge` 점은 스크린리더에 "(새 소식)"으로 읽힙니다.
- `md`(Medium)는 보이는 높이는 32지만 터치 화면에서는 눌림 영역이 44px로 넓어집니다.

## Props 요약

`items`(필수: `value` · `label` · `icon` · `badge` · `disabled`) · `value` · `defaultValue` · `onChange` · `all` · `allLabel` · `variant` · `size` · `shape` · `fade`와 나머지 `<div>` 속성. 자세한 표는 docs의 Category 페이지를 봅니다.
