# SegmentedControl 사용 규칙

`SegmentedControl`을 쓰거나 고칠 때 **이 문서대로 쓰는 것을 권장**합니다. 출처는 Figma `Segmented Control`(node `2208:23251`)과 `Segmented Control Guidelines`(node `2208:23564`)입니다. Figma와 이 문서가 다르면 Figma가 맞습니다.

- **여러 옵션 중 하나를 바로 바꾸는 토글형 선택 컨트롤**입니다. 화면 전체가 아니라 같은 영역의 보기 방식만 바뀝니다.
- 회색 트랙 위에서 선택된 항목이 흰 칩(그림자)으로 보입니다.
- 클라이언트 컴포넌트(`"use client"`)입니다. 선택 상태와 키보드 이동을 다룹니다. 서버 컴포넌트에서 import해도 되지만 `onChange`는 클라이언트 컴포넌트에서 넘깁니다.
- 반응형 웹(모바일웹 ~ PC)에서 같은 컴포넌트를 씁니다. 모바일에서 꽉 채우려면 `fullWidth={{ base: true, tablet: false }}`처럼 씁니다.

## 언제 쓰나요

같은 데이터를 보는 방식을 바꿀 때 써요. 화면의 내용(섹션)이 바뀌면 Tab을 써요.

|      | Segmented Control              | Tab                        |
| ---- | ------------------------------ | -------------------------- |
| 목적 | 같은 내용을 보는 방식을 바꿔요 | 화면의 내용(섹션)을 바꿔요 |
| 개수 | 2~6개                          | 2~6개                      |
| 모양 | 트랙 위에 선택된 칩            | 밑줄형                     |
| 예시 | 목록/격자, 일/주/월            | 홈, 시세, 내 자산          |

Tab은 MINT에 아직 없습니다.

## 구성

종류와 크기를 골라요.

| 구성            | 선택지                                                  | 쓰는 곳                                |
| --------------- | ------------------------------------------------------- | -------------------------------------- |
| 크기(`size`)    | `sm`(Small 32) · `md`(Medium 40, 기본) · `lg`(Large 48) | 기본은 Medium. 구간별 값도 받아요      |
| 아이콘(`icon`)  | 항목마다 켜고 끌 수 있어요                              | 레이블이 짧을 때 보조로만 써요         |
| 개수(`items`)   | 2~6개                                                   | 4개 넘으면 한 줄에 들어가는지 확인해요 |
| 폭(`fullWidth`) | 내용 폭(기본) · 부모 폭                                 | 항목은 언제나 같은 폭으로 나눠요       |

- **선택 색**: 선택 안 됨은 트랙(`fill/neutral-weak`) 위 회색 글자(`text/secondary`), 선택됨은 흰 칩(`fill/white`) + 그림자 · 진한 글자(`text/strong`).
- 크기별 수치: Large 트랙 48·칩 40·좌우 16·글자 label-1 · Medium 40·32·12·label-2 · Small 32·24·8·label-3. 트랙 안쪽 여백 4.
- `md`·`sm`은 터치 화면에서 눌림 영역을 44px로 넓힙니다.
- **애니메이션**: 선택이 바뀌면 흰 칩이 옆 칸으로 미끄러집니다(0.25초). CSS로만 움직여서 서버 렌더 첫 화면부터 제자리에 있고, 움직임 줄이기 설정이면 바로 옮겨집니다.

```tsx
const [view, setView] = useState("list");

<SegmentedControl
  aria-label="보기 방식"
  value={view}
  onChange={setView}
  items={[
    { value: "list", label: "목록", icon: <ListIcon /> },
    { value: "grid", label: "격자", icon: <SquaresFourIcon /> },
  ]}
/>;
```

## 사용 규칙

항상 하나가 선택돼 있어야 해요.

- 권장: 옵션 이름은 1~4자로 짧게 써요.
- 권장: 처음에는 기본값 하나를 선택해 둬요(`defaultValue`, 생략하면 첫 항목).
- 금지: 선택 없음 상태를 만들지 않아요.
- 금지: 5개 이상이 한 줄에 안 들어가면 Select나 Tab으로 바꿔요(최대 6개).

## 접근성

- `role="radiogroup"` 안의 `role="radio"` 버튼입니다. `aria-label`(또는 `aria-labelledby`)로 묶음 이름을 꼭 줍니다.
- Tab으로는 선택된 항목 하나에만 들어오고, ←·→(↑·↓)로 옮기면 바로 선택됩니다. Home·End는 처음·끝입니다.
- 선택은 색만이 아니라 흰 칩(배경)과 글자 대비로 함께 구분됩니다.
