# Tab 사용 규칙

`Tab`을 쓰거나 고칠 때 **이 문서대로 쓰는 것을 권장**합니다. 출처는 Figma `Tab`(node `2325:40134`)과 `Tab Guidelines`(node `2325:40341`)입니다. Figma와 이 문서가 다르면 Figma가 맞습니다.

- **같은 화면에서 보는 내용(섹션)을 바꾸는 밑줄형 탭**입니다. 항상 하나가 선택돼 있고 2~6개입니다.
- 클라이언트 컴포넌트(`"use client"`)입니다. 선택 상태와 키보드 이동을 다룹니다. `onChange`는 클라이언트 컴포넌트에서 넘깁니다.

## 언제 쓰나요

|      | Category                           | Tab                             |
| ---- | ---------------------------------- | ------------------------------- |
| 목적 | 같은 목록을 거르거나 분류를 골라요 | 같은 화면의 내용(섹션)을 바꿔요 |
| 모양 | 알약형 칩                          | 밑줄형                          |
| 개수 | 3~7개                              | 2~6개                           |
| 선택 | 전체를 포함해 하나만 선택해요      | 항상 하나가 선택돼요            |

## 구성

| 구성                        | 선택지                               | 쓰는 곳                                                                                                                                                                                                       |
| --------------------------- | ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 배치(`layout`)              | `fill`(기본) · `hug`                 | 5개 이하는 fill, 6개이거나 이름이 길면 hug. fill도 이름이 안 들어가면 이름 폭을 지키며 가로로 스크롤(터치·트랙패드는 밀어서, 마우스는 끌어서. 끈 뒤에는 탭이 선택되지 않고, 놓으면 관성으로 조금 더 미끄러짐) |
| 크기(`size`)                | `lg`(48, 기본) · `md`(40) · `sm`(32) | 구간별 값도 받아요(`{ base: "lg", desktop: "md" }`)                                                                                                                                                           |
| 가장자리 그라데이션(`fade`) | 켬(기본) · 끔                        | 탭이 넘칠 때만 스크롤할 쪽에 나타나요(자동). Category와 같아요                                                                                                                                                |
| 뱃지(`badge`)               | 탭마다 켜고 끔                       | 새 소식이 있는 탭에만 점으로 표시해요                                                                                                                                                                         |
| 상태                        | Normal · Disabled(`disabled`)        | 눌림 상태는 따로 만들지 않아요                                                                                                                                                                                |

- **선택 표시**: 선택된 탭은 굵은 글자(strong) + 아래 2px 밑줄, 나머지는 보통 굵기 회색 글자(tertiary). 색만으로 알리지 않고 굵기와 밑줄을 함께 바꿉니다.

```tsx
const [section, setSection] = useState("home");

<Tab
  aria-label="내 정보"
  value={section}
  onChange={setSection}
  items={[
    { value: "home", label: "홈" },
    { value: "market", label: "시세", badge: true },
    { value: "assets", label: "내 자산" },
  ]}
/>;
```

## 사용 규칙

| 구분 | 내용                                                            |
| ---- | --------------------------------------------------------------- |
| 권장 | 탭 이름은 2~6자 명사로 써요                                     |
| 권장 | 현재 탭은 밑줄과 굵은 글자로 함께 표시해요(자동)                |
| 금지 | 탭 안에 또 탭을 넣지 않아요                                     |
| 금지 | 탭으로 다른 페이지로 이동하지 않아요. 이동은 링크나 버튼을 써요 |

## 접근성

- 묶음은 `tablist`, 탭은 `tab`(`aria-selected`)으로 읽힙니다. **`aria-label`을 꼭 줍니다.**
- 키보드: <kbd>Tab</kbd>으로 선택된 탭에 들어오고, <kbd>←</kbd>·<kbd>→</kbd>로 옆 탭을 선택하고, <kbd>Home</kbd>·<kbd>End</kbd>로 처음·끝 탭을 선택합니다(비활성 탭은 건너뜀).
- `badge` 점은 스크린리더에 "(새 소식)"으로 읽힙니다.
- `md`·`sm`은 터치 화면에서 눌림 영역이 44px로 넓어집니다.
- 내용 영역(`tabpanel`)과의 연결(`aria-controls`)은 아직 지원하지 않습니다.

## Props 요약

`items`(필수: `value` · `label` · `badge` · `disabled`) · `value` · `defaultValue` · `onChange` · `size` · `layout` · `fade`와 나머지 `<div>` 속성. 자세한 표는 docs의 Tab 페이지를 봅니다.
