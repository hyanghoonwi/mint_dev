# Label 사용 규칙

`Label`을 쓰거나 고칠 때 **이 문서대로 쓰는 것을 권장**합니다. 출처는 Figma `Label`(node `2332:41220`)과 `Label Guidelines`(node `2332:41302`)입니다. Figma와 이 문서가 다르면 Figma가 맞습니다.

- **입력 칸 위에 붙는 이름**입니다. Text Field, Textarea, Select, Form에서 조합해 씁니다.
- 서버 컴포넌트에서 그대로 쓸 수 있습니다(`"use client"` 없음).

## 언제 쓰나요

Label은 무엇을 입력하는지 알려 주고, 예시는 Placeholder가 맡아요.

|      | Label                       | Placeholder                         |
| ---- | --------------------------- | ----------------------------------- |
| 목적 | 입력할 내용의 이름을 알려요 | 입력 예시를 보여 줘요               |
| 모양 | 입력 칸 위의 굵은 글자      | 입력 칸 안의 회색 글자              |
| 위치 | 입력 칸 바로 위             | 입력 칸 안에 있고 입력하면 사라져요 |

## 구성

| 구성                      | 선택지                            | 쓰는 곳                                        |
| ------------------------- | --------------------------------- | ---------------------------------------------- |
| 크기(`size`)              | `lg` 16 · `md` 14(기본) · `sm` 12 | 입력 칸 크기에 맞춰 골라요. 구간별 값도 받아요 |
| 상태(`disabled`)          | Normal · Disabled                 | 입력 칸을 쓸 수 없으면 글자색을 흐리게 해요    |
| 필수(`required`)          | 켜고 끔                           | 필수 입력일 때 라벨 옆에 빨간 `*`를 붙여요     |
| 도움말 아이콘(`helpIcon`) | 켜고 끔 · 직접 만든 요소          | 설명이 더 필요할 때 켜요                       |

```tsx
<Label htmlFor="phone" required>
  휴대폰 번호
</Label>
<input id="phone" placeholder="010-0000-0000" />
```

## 사용 규칙

| 구분 | 내용                                                                                 |
| ---- | ------------------------------------------------------------------------------------ |
| 권장 | 이름, 휴대폰 번호처럼 명사로 짧게 써요                                               |
| 권장 | 필수 입력일 때만 `required`를 켜요                                                   |
| 권장 | 입력 칸마다 Label을 붙여요(Placeholder만 있으면 입력하는 순간 무엇인지 알 수 없어요) |
| 금지 | 글자색을 임의로 바꾸지 않고 시맨틱 색만 써요                                         |

## 접근성

- 글자는 `<label>`입니다. **`htmlFor`로 입력 칸의 `id`와 이어 두면** 라벨을 눌러도 입력 칸에 포커스가 가고, 스크린리더가 입력 칸 이름으로 읽습니다.
- `required`의 `*`는 눈에만 보이고(`aria-hidden`), 스크린리더는 "(필수)"로 읽습니다. 입력 칸에는 `required`나 `aria-required`를 따로 줍니다.
- 도움말 아이콘은 `<label>` 밖에 놓입니다. 누르는 동작이 있으면 `aria-label`이 있는 버튼으로 만들어 넘깁니다.
- `true`로 켠 기본 물음표 아이콘은 장식이라 스크린리더가 읽지 않습니다.

## Props 요약

`children`(필수) · `htmlFor` · `size` · `required` · `disabled` · `helpIcon`과 나머지 `<div>` 속성. 자세한 표는 docs의 Label 페이지를 봅니다.
