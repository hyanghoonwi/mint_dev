# Calendar 사용 규칙

`Calendar`를 쓰거나 고칠 때 이 문서를 따릅니다. **임시 컴포넌트**입니다(Figma 시안 전, 2026-11-11). 시안이 나오면 칸 크기·점·색을 맞추고 이 문서에 Figma 노드를 적습니다. props(API)는 유지합니다.

## 설계 원칙

- **날짜는 문자열**(`YYYY-MM-DD`, 달은 `YYYY-MM`)입니다. `Date`를 받지 않습니다.
- **계산은 `_internal/date.ts`의 UTC 순수 함수**로 합니다. 서버(UTC)와 브라우저(KST) 결과가 같아 하루가 밀리지 않습니다. 날짜 라이브러리를 쓰지 않습니다.
- **현재 시각을 읽지 않습니다.** 오늘은 `today`(필수)로 받습니다(렌더 중 `new Date()` 금지, hydration 불일치).
- **바깥 데이터는 데이터로 받습니다.** 일정 점(`marks`)·공휴일(`holidays`)은 함수가 아니라 객체라서 서버 컴포넌트에서도 넘길 수 있습니다. 달이 바뀌면 `onMonthChange`로 알리고, 그 달의 데이터는 사용하는 쪽이 불러옵니다.
- **주말은 계산, 공휴일은 데이터**입니다. 음력 명절·대체공휴일은 계산할 수 없습니다.

## 구성(임시 값)

| 구성         | 값                                                                                                       |
| ------------ | -------------------------------------------------------------------------------------------------------- |
| 크기(`size`) | `md` 칸 48 · 숫자 원 32 · Body 4 Medium / `lg` 칸 56 · 원 40 · Body 2 Medium. 폭은 부모를 꽉 채워 7칸    |
| 점           | 4px 원, 간격 3px, 숫자 아래 4px. 최대 3개                                                                |
| 선택         | 브랜드 원 · 흰 글자                                                                                      |
| 오늘         | 브랜드 테두리 1px(색만으로 구분하지 않음)                                                                |
| 글자 색      | 일요일·공휴일 `text-danger`, 토요일 `text-brand`, 나머지 `text-primary`, 앞뒤 달·막힌 날 `text-disabled` |
| 머리글       | 이전·다음 `IconButton`(sm) + 가운데 "2026년 11월"(Heading 3 Bold)                                        |

## 접근성

- `role="grid"` 안에 `row` · `columnheader` · `gridcell`, 날짜는 `button`입니다.
- 버튼 이름: "11월 12일 수요일" + "오늘" + 공휴일 이름 + 일정(라벨 또는 "일정 N개").
- Tab은 한 칸(선택한 날 → 오늘 → 1일)에만 들어오고, ←→↑↓·PageUp·PageDown·Home·End로 옮깁니다. 보이는 달 밖으로 옮기면 달도 바뀝니다.
- 달 제목은 `aria-live="polite"`라 달이 바뀌면 읽힙니다. 앞뒤 달 날짜는 흐린 숫자만 보이고 스크린리더는 건너뜁니다.

## 아직 없는 것

기간 선택(`mode="range"`), 여러 날 선택, 주 보기, 날짜 입력창(DatePicker). 필요해지면 이 문서에 설계를 먼저 적습니다.
