# Switch 사용 규칙

`Switch`를 쓰거나 고칠 때 **이 문서대로 쓰는 것을 권장**합니다. 출처는 Figma `Switch`(node `2325:40822`)와 `Switch Guidelines`(node `2325:40913`)입니다. Figma와 이 문서가 다르면 Figma가 맞습니다.

- **누르면 바로 켜지고 꺼지는 컨트롤**입니다. 설정을 즉시 적용할 때 쓰고, 제출할 때 적용되는 선택은 `Checkbox`를 씁니다.
- 서버 컴포넌트에서 그대로 쓸 수 있습니다(`"use client"` 없음). 켜짐·꺼짐 모양은 CSS(`peer-checked`)가 그립니다. `onChange`를 넘길 때만 클라이언트 컴포넌트 안에서 씁니다.
- 진짜 `<input type="checkbox" role="switch">`를 `<label>`로 감쌌습니다. 레이블을 눌러도 켜지고, 폼 제출(`name`·`value`)·키보드(<kbd>Space</kbd>)·스크린리더가 그대로 동작합니다.

## 언제 쓰나요

즉시 적용되는 설정에만 써요.

|      | Switch                  | Checkbox                  |
| ---- | ----------------------- | ------------------------- |
| 반영 | 누르면 바로 적용돼요    | 제출할 때 적용돼요        |
| 선택 | 켜짐과 꺼짐 두 가지예요 | 여러 개 중 고를 수 있어요 |
| 예시 | 알림 켜기, 다크 모드    | 약관 동의, 관심 분야      |

## 구성

켜짐 여부와 상태를 골라요.

| 구성             | 선택지                      | 설명                                                           |
| ---------------- | --------------------------- | -------------------------------------------------------------- |
| 켜짐(`checked`)  | False · True                | True가 켜진 상태예요. 제어(`checked`)·비제어(`defaultChecked`) |
| 상태             | Normal · Pressed · Disabled | Hover는 Pressed와 같아요. 비활성은 `disabled`                  |
| 레이블(children) | 켜고 끌 수 있어요           | 레이블 없이 쓰면 `aria-label`을 꼭 붙여요                      |

- **크기는 하나**입니다(트랙 44×24, 손잡이 20). `size` prop이 없습니다.
- **색**: 꺼짐 gray/200(트랙, `fill-neutral-medium`) → 누름 gray/300 → 비활성 gray/100(그림자 없음). 켜짐 brand(`fill-brand`) → 진한 brand → 연한 파랑(`fill-brand-weak-pressed`). 손잡이는 항상 흰색입니다.

```tsx
<Switch name="push" defaultChecked>
  푸시 알림
</Switch>
```

## 사용 규칙

| 구분 | 내용                                                             |
| ---- | ---------------------------------------------------------------- |
| 권장 | 설정 이름을 옆에 레이블로 적어 무엇을 켜는지 알려요              |
| 권장 | 켜짐과 꺼짐이 색과 위치로 분명히 구분돼요(자동)                  |
| 금지 | 제출이 필요한 선택에는 쓰지 않아요. Checkbox를 써요              |
| 금지 | "꺼짐" 같은 부정 표현으로 이름 짓지 않아요. "알림 받기"처럼 써요 |

## 접근성

- 스크린리더는 "스위치, 켜짐/꺼짐"으로 읽고, <kbd>Space</kbd>로 켜고 끕니다.
- **레이블이 없으면 `aria-label`을 꼭 줍니다.**
- 켜짐 여부를 색만으로 알리지 않습니다. 손잡이가 오른쪽(켜짐) · 왼쪽(꺼짐)으로 옮겨 갑니다.
- 터치 화면에서는 눌림 영역이 44px 이상으로 넓어집니다. 움직임 줄이기 설정이면 손잡이가 바로 옮겨집니다.

## Props 요약

`children` · `checked` · `defaultChecked` · `onChange` · `disabled`와 나머지 `<input>` 속성(`name`·`value`·`aria-label` 등). 자세한 표는 docs의 Switch 페이지를 봅니다.
