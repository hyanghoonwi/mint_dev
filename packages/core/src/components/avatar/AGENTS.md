# Avatar 사용 규칙

`Avatar`와 `AvatarGroup`을 쓰거나 고칠 때 **이 문서대로 쓰는 것을 권장**합니다. 출처는 Figma `Avatar Guidelines`(node `2200:3802`)와 `Avatar`(node `2200:3044`)입니다. Figma와 이 문서가 다르면 Figma가 맞습니다.

- **사용자나 대상을 나타내는 프로필 칸**입니다. 이미지, 이름 첫 글자, 기본 아이콘 중에서 고르고 크기와 모양을 정합니다.
- 서버 컴포넌트에서 그대로 쓸 수 있습니다(`"use client"` 없음). `onClick`을 넘길 때만 클라이언트 컴포넌트 안에서 씁니다.
- 반응형 웹(모바일웹 ~ PC)에서 같은 컴포넌트를 씁니다.

## 언제 쓰나요

대상을 대표하는 작은 이미지에 씁니다.

|      | Avatar                   | Thumbnail                  |
| ---- | ------------------------ | -------------------------- |
| 목적 | 사람이나 대상을 나타내요 | 콘텐츠 이미지를 보여 줘요  |
| 모양 | 원형 또는 둥근 사각형    | 비율을 고를 수 있는 사각형 |
| 예시 | 프로필, 거래소, 작성자   | 콘텐츠 카드 이미지         |

콘텐츠 카드 이미지처럼 비율이 필요한 이미지는 Avatar가 아니라 Thumbnail입니다(MINT에는 아직 없습니다).

## 구성

종류, 크기, 상태를 골라요.

| 구성          | 선택지                 | 설명                                                        |
| ------------- | ---------------------- | ----------------------------------------------------------- |
| 종류(Type)    | Image · Initial · Icon | 사진이 없으면 이름 첫 글자, 그것도 없으면 기본 아이콘이에요 |
| 모양(Variant) | Person · Brand         | 사람은 원형, 브랜드는 둥근 사각형이에요                     |
| 크기          | 24 · 32 · 40 · 48 · 64 | 목록에는 40, 상세 화면에는 64를 써요                        |
| 뱃지          | Dot · Number           | 새 소식은 Dot, 개수는 Number(99+)로 알려요                  |
| Avatar Group  | 겹쳐 보여요            | 넘치면 +N으로 줄여요                                        |

- **종류는 `src` → `name` → `icon` 순으로 자동**입니다. `src`가 있으면 Image, 없고 `name`이 있으면 Initial, 둘 다 없으면 Icon(기본은 사용자 아이콘)입니다.
- 모양은 `variant`입니다. 사람은 `person`(기본, 원형), 서비스·코인·조직 같은 브랜드는 `brand`(둥근 사각형)입니다.
- 크기는 `size`입니다(기본 40). **같은 목록에서는 크기를 하나로 맞춥니다.**
- 뱃지는 `badge`입니다. 새 소식은 `"dot"`, 개수는 숫자(99를 넘으면 `99+`)를 줍니다. 배지 크기는 `badgeSize`(`xs`~`xl`)로 따로 고를 수 있고, 생략하면 아바타 크기에 맞춥니다.
- 눌리는 아바타는 `onClick`을 주면 됩니다. hover와 pressed는 같은 색이고, `disabled`는 누를 수 없는 상태입니다.

```tsx
<Avatar src={user.image} name={user.name} size={40} />      {/* 목록 */}
<Avatar src={user.image} name={user.name} size={64} />      {/* 상세 화면 */}
<Avatar variant="brand" name="거래소" />                    {/* 사람이 아닌 대상 */}
<Avatar name={user.name} badge="dot" />                     {/* 새 소식 */}
<Avatar name={user.name} badge={12} />                      {/* 개수 */}
<AvatarGroup items={members} max={3} aria-label="참여자 5명" />
```

## 사용 규칙

**이미지가 없을 때를 항상 준비해요.**

| 구분 | 내용                                                             |
| ---- | ---------------------------------------------------------------- |
| 권장 | 이미지가 없으면 이름 첫 글자(Initial)나 기본 아이콘으로 대신해요 |
| 권장 | 같은 목록에서는 크기를 하나로 맞춰요                             |
| 금지 | 얼굴이 잘리는 이미지를 그대로 쓰지 않아요. 중앙 정렬을 확인해요  |
| 금지 | Avatar Group을 5개 넘게 펼치지 않아요. +N으로 줄여요             |

- **항상 `name`을 함께 줍니다.** 이미지가 없을 때 첫 글자로 대신하고, 스크린리더가 읽을 이름도 됩니다. `src`가 비어 있으면(`undefined`, 빈 문자열) 이름 첫 글자나 아이콘으로 대신하고, 이미지를 불러오지 못하면 회색 바탕만 보입니다.
- 이미지는 가운데를 기준으로 꽉 채워 잘립니다(`object-cover`). 얼굴이 가운데에 오는 이미지를 쓰세요.
- `AvatarGroup`은 `max`(기본 3)를 **5 이하**로 둡니다. 더 많으면 넘친 수가 `+N`으로 줄어듭니다.
- `AvatarGroup`은 **오른쪽이 항상 위**로 겹칩니다(맨 오른쪽, 그리고 `+N` 칸이 맨 위).

## 접근성

- 이미지나 아이콘만 쓰는 아바타에도 `name`이나 `aria-label`을 붙입니다. 이름이 있으면 `role="img"`로 읽힙니다.
- 눌리는 아바타(`onClick`)는 `name`(또는 `aria-label`)이 버튼의 이름이 됩니다. 이름이 없으면 스크린리더가 무엇인지 알 수 없습니다.
- 뱃지는 화면에만 보입니다. 개수를 소리로도 알려야 하면 `aria-label`에 적습니다(예: `김민수, 새 알림 3개`).
- `AvatarGroup`에는 `aria-label`로 몇 명인지 알려 줍니다(예: `참여자 5명`).
- 키보드 포커스 링은 눌리는 아바타에서 항상 보입니다(`focus-visible`).

## Props 요약

- `Avatar`: `size` · `variant` · `src` · `name` · `icon` · `badge` · `disabled` · `onClick`과 나머지 `<div>` 속성
- `AvatarGroup`: `items`(필수) · `size` · `max` · `count`와 나머지 `<div>` 속성

자세한 표는 docs의 Avatar 페이지를 봅니다.
