# Tooltip 사용 규칙

`Tooltip`을 쓰거나 고칠 때 **이 문서대로 쓰는 것을 권장**합니다. 출처는 Figma `Tooltip`(node `2286:32590`)과 `Tooltip Guidelines`(node `2286:33092`)입니다. Figma와 이 문서가 다르면 Figma가 맞습니다.

- **버튼 위에 마우스를 올리거나 키보드로 포커스했을 때 짧은 보조 정보(이름·단축키)를 보여 주는 말풍선**입니다. 중요한 정보나 눌러야 하는 액션은 넣지 않습니다.
- 클라이언트 컴포넌트(`"use client"`)입니다. 서버 컴포넌트에서 import해도 됩니다(열림 상태를 안에서 관리).
- 위치는 CSS(absolute)로만 정합니다. 포털이나 화면 크기 측정이 없어서 서버 렌더와 결과가 같습니다. 그래서 화면 가장자리에서 자동으로 뒤집히지 않으니, 가장 잘 보이는 `position`을 직접 고릅니다.
- 대상을 감싸는 `<span class="relative inline-flex">`가 생깁니다. `overflow: hidden` 영역 안에서는 말풍선이 잘릴 수 있습니다.

## Toast와 차이

|        | Tooltip                         | Toast                     |
| ------ | ------------------------------- | ------------------------- |
| 목적   | 대상의 이름이나 단축키를 알려요 | 행동 결과를 알려요        |
| 나타남 | Hover나 포커스에서 나타나요     | 행동 뒤 자동으로 나타나요 |
| 예시   | 저장, ⌘C                        | 저장했어요                |

## 구성

| 구성                      | 선택지                              | 설명                                                                                                 |
| ------------------------- | ----------------------------------- | ---------------------------------------------------------------------------------------------------- |
| 크기(`size`)              | `sm` · `md` · `lg`                  | 높이 30 · 36 · 42, 글자 12 · 13 · 14(Caption 1 · Body 5 · Body 4 Medium). 구간별 값도 받음           |
| 위치(`position`)          | `top` · `bottom` · `left` · `right` | 대상 기준. 화면 가장자리를 피해 가장 잘 보이는 위치를 골라요. 구간별 값도 받음(화살표 방향도 따라감) |
| 화살표 정렬(`arrowAlign`) | `start` · `center` · `end`          | 위·아래면 왼쪽·가운데·오른쪽, 왼쪽·오른쪽이면 위·가운데·아래. Figma의 Left · Center · Right          |
| 단축키(Figma `Shortcut`)  | `label`에 단축키 글자               | 켜면 이름 대신 단축키 글자만 보여 줘요(`label="⌘C"`). 모양은 같아요                                  |

- **색**: 말풍선 `gray-700`(아토믹, Figma가 직접 씀) · 글자 `text-on-fill`. 그림자는 떠 있는 요소용 `shadow-floating`.
- **모양**: 모서리 10 · 12 · 14, 패딩 10×6 · 12×8 · 14×10, 최대 폭 240(넘으면 줄바꿈). 화살표가 모서리(`start`·`end`)에 붙으면 그 모서리는 각집니다. 화살표 칸 6 · 8 · 10.
- **위치 맞춤**: 화살표 끝이 대상의 가운데를 가리킵니다. 대상과 4px 떨어집니다.
- **열림**: 마우스를 올리면(마우스 포인터만) 또는 포커스하면 열리고, 벗어나거나 포커스가 빠지거나 <kbd>Esc</kbd>를 누르면 닫힙니다. 말풍선 위로 마우스를 옮겨도 닫히지 않습니다. `open`·`onOpenChange`로 직접 제어할 수도 있습니다.

- **반응형**: `position={{ base: "bottom", desktop: "right" }}`처럼 구간마다 위치를 바꿀 수 있습니다. 모바일에서 옆으로 펼칠 공간이 없을 때 씁니다. 네 방향 화살표를 모두 그려 두고 CSS로 맞는 것만 보여 줘서 JS로 화면 폭을 읽지 않습니다.

```tsx
<Tooltip label="공유">
  <IconButton icon={<ShareNetworkIcon />} aria-label="공유" />
</Tooltip>
<Tooltip label="⌘C" position="bottom" arrowAlign="start" size="sm">
  <Button color="secondary">복사</Button>
</Tooltip>
```

## 사용 규칙

| 구분 | 내용                                               |
| ---- | -------------------------------------------------- |
| 권장 | 아이콘만 있는 버튼에 이름을 알려 줘요              |
| 권장 | Hover뿐 아니라 키보드 포커스에서도 보여 줘요(자동) |
| 금지 | Tooltip 안에 링크나 버튼을 넣지 않아요             |
| 금지 | 반드시 읽어야 하는 안내를 Tooltip에만 두지 않아요  |

- 한 줄로 짧게 씁니다.
- 터치 화면에는 hover가 없어서 말풍선이 보이지 않을 수 있습니다. 꼭 필요한 정보는 화면에 글자로 둡니다.
- `disabled` 버튼은 마우스·포커스 이벤트가 없어서 열리지 않습니다.

## 접근성

- 말풍선은 `role="tooltip"`이고, 대상의 `aria-describedby`로 연결되어 스크린리더가 대상과 함께 읽습니다.
- 대상은 포커스를 받을 수 있는 요소(버튼·링크)여야 합니다. 아이콘만 있는 버튼은 `aria-label`도 따로 붙입니다.
- <kbd>Esc</kbd>로 포인터를 옮기지 않고도 닫을 수 있습니다.

## Props 요약

`label`(필수) · `children`(대상 요소 하나) · `position`(구간별) · `arrowAlign` · `size`(구간별) · `open` · `onOpenChange`와 나머지 `<span>` 속성(감싸는 요소). 자세한 표는 docs의 Tooltip 페이지를 봅니다.
