# Live Status 사용 규칙

`LiveStatus`를 쓰거나 고칠 때 **이 문서대로 쓰는 것을 권장**합니다. 출처는 Figma `Live Status`(node `2372:79475`)와 `Live Status Guidelines`(node `2372:79509`)입니다. Figma와 이 문서가 다르면 Figma가 맞습니다.

- **데이터가 실시간으로 반영되는지 점과 글자로 알리는 표시**입니다. 제목 옆이나 카드 상단에 작게 붙여 씁니다.
- 클라이언트 컴포넌트입니다(`"use client"`). 링 모션을 Web Animations API로 걸고 화면 안 링의 순서를 알아야 해서입니다. 서버 컴포넌트에서 import해도 됩니다.
- 눌러도 동작이 없는 표시 전용입니다.

## 구성

| 구성           | 선택지   | 설명                                    |
| -------------- | -------- | --------------------------------------- |
| 켜짐(`active`) | On · Off | On은 빨간 점과 링, Off는 회색 점        |
| 문구(`label`)  | 글자     | 기본 "실시간 반영 중"(Off는 "일시정지") |

- **점**: 지름 8, 점과 글자 사이 8. On은 `fill-danger-pressed`(Figma 값 `#F73631` = atomic red-500), Off는 `icon-tertiary`(`#7E889A` = gray-500). 글자는 Body 4 Regular `text-tertiary`입니다.
- **링 모션(Figma, 2026-11)**: 1.8초 반복, 1배 → 3.2배로 커지며 투명도 0.55 → 0, easing `cubic-bezier(.2,.6,.3,1)`. `element.animate`(Web Animations API)로 걸고, 같은 화면에 여러 개 있으면 링의 화면 순서대로 0.26초씩 늦게 시작합니다(`data-mint-ping`으로 링을 찾음). 지연이 1.8초를 넘지 않게 7칸을 돌려 씁니다.
- **서버 렌더·움직임 줄이기**: 서버 렌더와 첫 화면, `prefers-reduced-motion: reduce`에서는 움직이지 않고 Figma의 정지 모양(링 지름 18, 투명도 25%)입니다. 애니메이션은 마운트 뒤(`useEffect`)에만 시작해서 hydration이 어긋나지 않습니다.

## 접근성

- 점은 `aria-hidden`이고 상태는 글자가 알립니다. 색만으로 구분하지 않으므로 Off일 때 문구도 함께 바꿉니다.
- 상태가 바뀔 때 스크린리더에 알리려면 `role="status"`(또는 `aria-live`)를 직접 줍니다. 기본은 읽기만 하는 일반 글자입니다.

## 사용 규칙

| 구분 | 내용                                                 |
| ---- | ---------------------------------------------------- |
| 권장 | 실시간으로 갱신되는 값 옆에 두고 멈추면 Off로 바꿔요 |
| 금지 | 실시간이 아닌 값 옆에 On을 쓰지 않아요               |
| 금지 | 색만으로 구분하지 말고 글자도 함께 바꿔요            |

## Props 요약

`active` · `label`과 나머지 `<span>` 속성. 자세한 표는 docs의 Live status 페이지를 봅니다.
