# PriceChange 사용 규칙

`PriceChange`를 쓰거나 고칠 때 **이 문서대로 쓰는 것을 권장**합니다. 출처는 Figma `Price Change`(node `2289:34039`)와 `Price Change Guidelines`(node `2289:34212`)입니다. Figma와 이 문서가 다르면 Figma가 맞습니다.

- **가격·시세가 오르내린 정도를 보여 주는 표시 전용 부품**입니다. 눌러도 동작이 없습니다. 상태나 분류(NEW, 인기, 마감임박)는 `Badge`가 알립니다.
- 상태·이벤트가 없어서 `"use client"`가 없습니다. 서버 컴포넌트에서 바로 씁니다.
- 반응형 웹(모바일웹 ~ PC)에서 같은 컴포넌트를 씁니다.

## Badge와 차이

|      | PriceChange                       | Badge               |
| ---- | --------------------------------- | ------------------- |
| 목적 | 가격, 시세가 오르내린 정도        | 상태·종류           |
| 동작 | 누르지 않아요(표시 전용)          | 누르지 않아요       |
| 색   | 방향에 따라 시세 색(up·down·flat) | 의미에 따라 상태 색 |
| 예시 | ▲ 100, +3.42%, ▼ 100, -1.20%      | NEW, 인기, 마감임박 |

## 구성

| 구성              | 선택지                 | 설명                                                                     |
| ----------------- | ---------------------- | ------------------------------------------------------------------------ |
| 방향(`direction`) | `up` · `down` · `flat` | 오르면 빨강 ▲, 내리면 파랑 ▼, 변동이 없으면 회색 −                       |
| 종류(`type`)      | `amount` · `percent`   | 금액에는 화살표만, 퍼센트에는 +, - 부호만. 한 표시에 둘을 함께 쓰지 않음 |
| 스타일(`variant`) | `text` · `weak`        | 글자만 / 연한 배경                                                       |
| 크기(`size`)      | `sm` · `md` · `lg`     | `sm` 표·목록, `md` 기본, `lg` 요약 카드. 구간별 값도 받음                |

- **색**: 글자 `text-up`(red-600) · `text-down`(blue-600) · `text-flat`(gray-600), 화살표 `icon-up`(red-500) · `icon-down`(blue-500), 보합 가로선은 글자색. `weak` 배경은 `fill-up-weak` · `fill-down-weak` · `fill-neutral-weak`.
- **크기**: 화살표는 모든 크기에서 7×5.5(보합 가로선 7×1.5)입니다.

  | `size`     | `text` 글자 · 높이         | `weak` 글자 · 높이        | 화살표 간격 | `weak` 패딩 · 모서리 |
  | ---------- | -------------------------- | ------------------------- | ----------- | -------------------- |
  | `sm`       | Caption 1 Medium(12/18) 18 | Label 3 Medium(12/16) 20  | 2           | 6×2 · 4              |
  | `md`(기본) | Body 4 SemiBold(14/22) 22  | Body 4 SemiBold(14/22) 28 | 3           | 8×3 · 8              |
  | `lg`       | Body 2 SemiBold(16/24) 24  | Body 2 SemiBold(16/24) 32 | 4           | 10×4 · 8             |

- `children`에는 **숫자만** 넣습니다(`"1,200"`, `"3.42%"`). 화살표와 부호는 컴포넌트가 붙입니다. 퍼센트의 `%`는 넘기는 값에 넣습니다.
- 숫자는 고정폭 숫자(`tabular-nums`)로 그려서 표 안에서 자릿수가 흔들리지 않습니다.

```tsx
<PriceChange direction="up">1,200</PriceChange>
<PriceChange direction="down" type="percent" variant="weak">1.20%</PriceChange>
<PriceChange direction="flat" type="percent" size={{ base: "sm", desktop: "md" }}>0.00%</PriceChange>
```

## 사용 규칙

| 구분 | 내용                                                                 |
| ---- | -------------------------------------------------------------------- |
| 권장 | 금액은 화살표(▲ ▼)로, 퍼센트는 부호(+, -)로 따로 써요                |
| 권장 | 소수점 둘째 자리까지 맞춰 써서 표 안에서 자릿수가 흔들리지 않게 해요 |
| 금지 | 눌러서 동작하는 요소로 쓰지 않아요                                   |
| 금지 | 한 줄에 크기를 섞어 쓰지 않고, 같은 목록에서는 크기를 하나로 맞춰요  |

- 0일 때는 `flat`을 씁니다. 퍼센트 보합은 부호 없이 `0.00%`입니다.
- 방향은 값의 부호로 사용하는 쪽이 정합니다(`direction={diff > 0 ? "up" : diff < 0 ? "down" : "flat"}`), `children`에는 절댓값을 넘깁니다.

## 접근성

- **방향을 색만으로 알리지 않아요:** 색을 구분하기 어려워도 화살표와 부호로 오름과 내림을 알 수 있어요.
- 화살표는 그림이라 스크린리더가 읽지 않아서, 앞에 "상승·하락·보합"을 숨긴 글자로 함께 읽어 줍니다.

## Props 요약

`direction`(필수) · `type` · `variant` · `size` · `children`(숫자)와 나머지 `<span>` 속성. 자세한 표는 docs의 Price change 페이지를 봅니다.
